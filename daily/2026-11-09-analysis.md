## 新上榜项目

### [google-deepmind/mujoco](https://github.com/google-deepmind/mujoco) — NEW ⭐ 16,448（+41）| C++ | 信源：中

知名老项目首入 tracker。

**它是什么**: 一个物理仿真引擎。研究者用它在电脑里搭出机械臂、四足机器人或人体肌肉模型，让它们在模拟的重力、碰撞和摩擦中运动，再用这些模拟去训练控制算法。

**解决什么问题**: 在真机上训练机器人又慢又贵，还容易撞坏设备。MuJoCo 让同一套控制策略先在仿真里跑上百万次，再迁移到真机。4.0 针对仿真里常见的两类失真：高速物体在一个时间步内直接穿过薄障碍物（推测接触 speculative contacts 解决），以及金属丝、黏土这类受力后不能复原的材料（弹塑性 elasto-plasticity 解决）。

**谁在用、怎么用**（来自 Issues/官方公告/HN）:
- 强化学习训练：#3247 讨论把批量 rollout 中的 MuJoCo 报错降为警告，避免一次数值异常中断整轮训练。
- 生物力学与机器人建模：HN 10-26 的帖子介绍了基于 MuJoCo 的 206 关节、700 块肌肉人体模型 MS-Human-700；9-06 有人发了在浏览器里用 MuJoCo 跑机器鸭踢球的 Show HN。
- 规模：官方 4.0 公告称 MuJoCo 每月约 360 万次 PyPI 下载，过去一年 45 位以上外部贡献者提交约 2,000 次；与 NVIDIA 合作 MuJoCo Warp，与 NVIDIA、Disney、TRI 等共同开发 Linux 基金会下的 Newton。

**社区怎么评价**:
- 正面: 4.0 公告讨论帖（Discussion #3773）11-07 发布；浏览器演示和拆包安装降低了试用门槛。
- 负面: 评论最多的 open issue 是平台兼容问题，#2275（39 条评论）是 Windows 11 上加载 DLL 失败，#639（38 条评论）是 AMD 显卡界面渲染错乱，均已挂了一年以上。HN 截至抓取时没有 4.0 的发布帖。
- 健康度: 16,448 stars、138 subscribers（约 119:1）、308 个 open issue/PR，仓库 2021-08 开源，11-08 仍有提交。成熟项目的比值偏高属于结构性现象，不构成热度失真信号。

**风险与争议**:
- **stability**: 4.0 含破坏性变更，`sidesite` 的肌腱绕行规则改了，依赖旧行为的模型结果会变。
- **升级兼容**: Python 包拆分后，从 3.x 升级须先 `pip uninstall -y mujoco` 再安装，否则 pip 可能删掉迁到 `mujoco-core` 的文件；官方提示拆包与 OpenUSD 文档以 `latest` 为准，不要看 `stable`。

**技术备注**: C/C++ 引擎，Python 绑定，Apache 2.0 许可；同仓含 JAX 版 MJX、Studio 可视化和 WebAssembly 构建。

### [anthropics/claude-quickstarts](https://github.com/anthropics/claude-quickstarts) — NEW ⭐ 19,460（+32）| Python | 信源：弱

知名老项目首入 tracker。

**它是什么**: Anthropic 官方的 Claude 示例项目合集。每个子目录是一个能直接跑起来的小应用，例如客服 Agent、财务数据分析助手、操作电脑的 computer use 演示、浏览器操作工具集，以及一组基于 Managed Agents 的 Slack、Linear、Sentry 集成示例。

**解决什么问题**: 开发者看完 API 文档后，往往还需要一份完整可运行的工程，才知道工具调用、沙箱、前端界面怎么拼在一起。这个仓库提供这样的起点，可以拷下来改成自己的应用。10-23 起示例统一固定到 `anthropic` Python SDK 2.0 和 `@anthropic-ai/sdk` 1.0，10-29 新增 Sentry 自动修复示例（#487），11-02 给 OpenShell 示例加了策略扩展（#531）。

**谁在用、怎么用**（来自 Issues）:
- 本地运行 computer use 演示：评论最多的 #42（25 条评论，noVNC 连不上）、#41（localhost 拒绝连接）、#85（API 连接错误）都是 2024 年用户按 README 起 Docker 容器时遇到的问题。
- 改造部署环境：#373 提议让 computer use 演示的 Docker 端口可通过环境变量配置。

**社区怎么评价**:
- 正面: 跟随 SDK 和模型版本持续更新，10 月以来几乎每周都有提交，新示例覆盖 Managed Agents 和浏览器工具集。
- 负面: 热门 issue 集中在 2024 年的安装与连接问题，至今仍是 open 状态，维护方没有逐一关闭。
- 健康度: 19,460 stars、176 subscribers（约 111:1）、234 个 open issue/PR，仓库 2024-08 创建，11-06 最后提交。HN、X、Reddit 未单独检索；结论主要来自 README、提交记录和 Issues。

**风险与争议**:
- **dependency**: Managed Agents 示例依赖 Anthropic 托管平台，示例代码固定在特定 SDK 主版本，升级 SDK 时要同步调整。
- **stability**: 示例只作为开发起点；computer use 演示的 Docker 网络问题长期没有统一答复。
- **cost**: computer use 和长流程 Agent 示例按 token 计费，跑通示例本身就有 API 开销。

**技术备注**: Python 与 TypeScript 混合，MIT 许可；子目录包括 `agents`、`autonomous-coding`、`browser-use-demo`、`computer-use-demo`、`customer-support-agent`、`financial-data-analyst`、`managed-agents` 等。
