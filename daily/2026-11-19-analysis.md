**主线二：前端三个库在三天内发版，两场发布在 HN 各拿到 370 分上下。** jQuery 在 11-17 同时发布 4.1.0 和 3.8.0，官方博客把 3.8.0 称为送别版本，3.x 分支今后只收关键安全修复和缺陷修复；两个版本都修了选择器标识符匹配的 ReDoS 问题。HN 上「jQuery 4.1.0」一帖 372 分、199 条评论。Solid 在同一天发布 2.0.0，距 1.0 过去五年，发布说明列的头两项是计算可以直接返回 Promise 或异步迭代器，以及开发构建对响应式错误给出稳定错误码、源码位置和修复建议；HN 上「Solid 2.0」一帖 371 分、116 条评论，11-18 已跟进 2.0.1。Svelte 在 11-18 发布 5.58.0，开发模式的 `__svelte_meta` 带上组件实例和 snippet 名，供 Svelte devtools 追踪（#19286、#19283）。三个项目的日增差别很大：Svelte +692，jQuery +266，Solid 只有 +40。

**主线三：技能生态里，评估工具发布了第一个大版本，插件库升到榜首。** NVIDIA SkillEvaluator 在 11-17 发布 v1.0.0，一天后用 v1.0.1 补齐 PyPI 包和 CI 包。新增的 HarnessCheck 检查一个技能在 Claude Code、Codex、Copilot CLI、Hermes、OpenClaw、OpenCode 六种运行环境里会不会被漏读、拒收或截断；第三层评估可以接入 NeMo Gym 后端。它 11-16 首次上榜时 1,746 星，今天 3,748 星。cursor/plugins 从 #8 升到 #1，11-18 继续合入 Hospitable、Fiscal AI、CreateOS、LMTY 等第三方插件。superpowers 和 ECC 两个大型框架仍在榜，名次各降 5 位和 2 位，superpowers 自 11-03 的 v7.0.2 之后没有新提交。

**主线四：Python 和 Node 的环境管理工具同榜，近期改动都落在安装链路的校验上。** uv 是 Rust 写的 Python 包和项目管理器，11-17 的 0.13.9 开始拒绝索引用别的包名提供的 wheel（#23261），并缩小 lockfile 体积、加快读取（#23184）。nvm 在 11-16 合入一组修复：`nvm use`、`install-latest-npm` 和全局包安装改为在项目目录之外运行 npm，`nvm debug` 不再让项目里的 `.npmrc` 配置 npm，镜像返回的控制字符不再输出到终端。Appwrite 11-17 的 2.7.3 是维护补丁，换用新的基础镜像和执行器来清掉镜像里的已知漏洞。Docker 管理面板 Arcane 在 11-18 发布 v3.1.0，新增 LDAP 登录和用户同步（#4822）。

**主线五：榜单解读提醒 — 名次不按日增排序，两个项目的星数增长和代码活动对不上。** PaperOrchestra 今天 +1,524 是全榜最高，名次是 #8；OpenVINO 只涨 +24，排在 #13，高于日增 +822 的 superpowers 和 +1,108 的 ECC。PaperOrchestra 三天从 1,587 星涨到 4,332 星，subscribers 28，比值约 155:1，11-15 之后没有新提交，这类增长需要结合后续的 issue 和复现反馈再判断。CLI-Anything 回到 #2，但仓库最后一次推送停在 09-22 的 README 修改，最新版本仍是 06-25 的 v0.4.0。另外，榜单的「今日」星数取自 Trending 页面，总星数取自 GitHub API，两者采样时间不同，相减对不上属正常。

### [jquery/jquery](https://github.com/jquery/jquery) — NEW ⭐ 60,020（+266）| JavaScript | 信源：中（知名老项目首入 tracker）

**它是什么**: 2009 年建仓的 JavaScript 库，用一套简短的写法操作网页元素、绑定事件、发 Ajax 请求。大量存量网站和 WordPress 主题、插件至今依赖它。

**为什么今天值得看**: 11-17 同时发布 4.1.0 和 3.8.0，官方博客标题是「Passing the Torch」。4.1.0 是 4.x 的第一个小版本，jqXHR 新增 `responseURL` 字段（#4339），自定义 Ajax transport 的完成回调可以改传一个对象。3.8.0 把 3.x 分支积压几年的修复一次发出，博客原话是「a send-off, not a comeback」，之后 3.x 只收关键安全修复和缺陷修复。两个版本都修复了选择器标识符正则的灾难性回溯：一长串十六进制转义后跟一个非法字符就能卡死页面。HN 上「jQuery 4.1.0」一帖 372 分、199 条评论。仓库现有 20,709 forks、3,114 subscribers、95 个 open issue。

**风险与争议**:
- **3.x 维护收尾**: 3.x 今后只收关键修复。还在用 3.7 及更早版本的站点至少应升到 3.8.0 拿到 ReDoS 修复，再按官方升级指南和 jQuery Migrate 插件评估迁到 4.x。

**技术备注**: JavaScript，MIT。发布后主分支移除了 dist 文件，构建产物从 CDN 和 npm 获取。首次进入本 tracker，此处按知名老项目做轻量记录，不做完整社区 grounding。
