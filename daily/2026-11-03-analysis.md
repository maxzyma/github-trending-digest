## 新上榜项目

### [vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop) — NEW ⭐ 9,903（+2,275）| Rust | 信源：中

**它是什么**: 一个命令行工具，让 AI 代理像人一样操作电脑上的普通应用。它读取操作系统给读屏软件用的无障碍元素树，给按钮、输入框编上号，代理按编号点击和输入，再重新读取一次确认结果。

**解决什么问题**: 常见的"电脑操作"Agent 靠截图让模型猜坐标，慢且容易点偏。agent-desktop 直接拿到界面元素的结构，每一步返回 JSON，任何语言写的 Agent 都能调用。它默认在后台运行，你可以继续用鼠标键盘；多个代理可以共用一个桌面，各有自己的光标。

**谁在用、怎么用**（来自 Issues/HN/X/评测）:
- 场景 1: 给编程 Agent 加上操作原生应用的能力。外部 PR 集中在补 Linux KDE/Wayland 支持（#380、#437）、macOS 27 修复（#399）和多应用并行（#436）；#21 有用户主动询问如何参与维护。
- 场景 2: macOS 自动化是主要使用面，问题也集中在这里：残留进程让所有列举命令失败（#355），Arc 浏览器无法读取界面（#465），语音备忘录上的操作一律报 AMBIGUOUS_TARGET（#494）。
- 场景 3: Linux 用户在等更多桌面环境支持，Hyprland、Sway 这类 wlroots 系合成器尚不支持（#386）。

**社区怎么评价**:
- 正面: 2026-05 作者以个人仓发 Show HN，99 分、44 条评论，赞许速度快、任何语言都能调用；flaviocopes 写了深度评测，DEV Community 也有介绍文。X 上 Vercel 的 Chris Tate 称它是"整台电脑版的 agent-browser"。
- 负面: HN 评论指出 Linux/Wayland 的无障碍支持时好时坏，Flutter、egui 这类自绘界面拿不到元素树；X 回复区有人问它和 Cua Driver 的区别，也有人指出多个代理共用登录态时无法追溯是谁做的操作。评测者建议不要直接在日常主力桌面上放权。Reddit 未找到讨论。
- 健康度: 19 个关注者，星数与关注者之比约 521:1，主要受仓库迁移影响；664 个 fork。open 计数 125 个，其中约 77 个是 PR。作者 lahfir 218 次提交，人类第二名 ctate 15 次。10-18 到 10-30 连发 v0.10.1、v0.11.1、v1.0.0、v1.0.1、v1.0.2。

**风险与争议**:
- **stability**: macOS 新版本兼容问题集中，Linux Wayland 支持不完整，自绘界面无法操作。
- **privacy**: 界面快照、剪贴板和截图会带出桌面上的私人内容；可选的 JEV 助手会把屏幕描述发给模型服务商。
- **bus_factor**: 一位作者贡献了绝大部分提交。

**技术备注**: Rust 命令行工具加 C 库，Apache-2.0 许可，`npm i -g agent-desktop` 安装。支持 macOS（需授予辅助功能权限）、Windows 和 Linux（需 at-spi2-core）。自带 `skills get desktop` 文档供 Agent 读取。

### [karpathy/nanochat](https://github.com/karpathy/nanochat) — NEW ⭐ 59,915（+321）| Python | 信源：中

**它是什么**: Andrej Karpathy 写的教学代码库，约 8,000 行，把训练一个聊天模型的全流程放在一起：分词、预训练、微调、强化学习、推理和网页聊天界面。2025 年 10 月发布时的说法是，租一台 8 卡 H100 机器，花约 100 美元、4 小时，就能训出一个能对话的小模型。

**解决什么问题**: 想弄懂 ChatGPT 这类模型怎么做出来的人，以前要拼凑多个框架和教程。nanochat 用一套短小、可读的代码跑通整条链路，你可以逐行读，也可以改一处再训一遍看效果。

**谁在用、怎么用**（来自 Issues/Discussions/HN）:
- 场景 1: 在不同硬件上复现训练。Discussion #28 记录在 NVIDIA DGX Spark 上训练，124 条评论；#215 讨论本地硬件能不能跑，#216 讨论在欧洲租 GPU。
- 场景 2: 训练速度竞赛和研究实验。PR #498 用 MuonH 优化器提交速度榜成绩；Discussion #420 做缩放律实验；进行中的 PR #800 要把项目改成一组研究实验的框架。
- 场景 3: 衍生移植。社区做了 TPU/JAX、Rust 和 ggml C++ 推理版本；Karpathy 2026 年 3 月的衍生项目 autoresearch 在 HN 拿到 208 分。

**社区怎么评价**:
- 正面: 首发 HN 帖 1,523 分、308 条评论；8,414 个 fork，说明很多人真的拉下来跑。据 Karpathy 在 X 上的进度帖，训到 GPT-2 水平的时间在 2026 年 3 月降到 2 小时以内。
- 负面: Mac 用户等了很久的 MPS/CPU 兼容 PR（#145，16 条评论）至今未合并。11-02 一天至少新开 14 个 PR，其中 12 个来自同一位贡献者，暂无维护者回应。Reddit 未检索到有效讨论。
- 健康度: 378 个关注者，星数与关注者之比约 158:1，对名人教学仓属常见水平；open issue 加 PR 共 139 个。master 最后一次提交在 2026-07-03，之后的推送在实验分支上。

**风险与争议**:
- **cost**: "100 美元"的前提是租 8 卡 H100，更大的 d32 档约 800 美元；普通笔记本和 Mac 跑不了训练。
- **bus_factor**: 只有 Karpathy 一人合并代码，主分支 4 个月没有更新。
- **stability**: 训出的模型是教学用的小模型，不适合直接用于生产。

**技术备注**: Python + PyTorch，MIT 许可。覆盖分词器训练、预训练、SFT、RL、KV 缓存推理和网页界面。本次回榜没有找到对应的新版本或作者动态。
