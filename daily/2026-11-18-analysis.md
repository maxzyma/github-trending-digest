## 本日主线

**主线一：榜单地图 — 没有新面孔，技能包和编码 Agent 工具占了 9 席。** 昨天的 claude-trading-skills、江山时序、SkillEvaluator、chrome-devtools-mcp、ffmpeg-skill 5 项离榜，6 个老项目回榜，总数从 14 项增到 15 项。今日可分 5 组：

- **Agent Skills 与开发方法框架**（5 项，最大盘）—— `elementalsouls/Claude-BugHunter`（RE 榜首，+1,005）、`mvanhorn/last30days-skill`（↑6，#2）、`google-labs-code/stitch-skills`（=，#7）、`obra/superpowers`（RE，#9，319,374 ⭐，+1,917）、`affaan-m/ECC`（RE，#13，305,553 ⭐）

- **Agent 接入产品界面**（2 项）—— `dream-num/univer`（↓2，#5，+1,774）、`ag-ui-protocol/ag-ui`（↓9，#10，+1,445）

- **非 AI 的开发者工具**（2 项）—— `getarcaneapp/arcane`（↓1，#6）、`sveltejs/svelte`（↑1，#12）

15 项今日合计 +12,675 星，昨天 14 项是 +8,610。增量最大的是 superpowers（+1,917）、Univer（+1,774）和 AG-UI（+1,445）；回榜的 6 项里，Claude-BugHunter 和 LoopForge 两天前刚离榜，cursor/plugins、superpowers、ECC 隔了两三周，minimind 上次在榜是 09-02。

**主线二：技能生态的关注点回到头部框架和垂直技能包。** 5 个技能项目里有 3 个是回榜老项目。superpowers 是一套让编码 Agent 先头脑风暴、写计划、再按测试驱动实现的开发方法框架，最新版本仍是 11-03 的 v7.0.2，之后没有新提交，今天却是全榜日增最高。ECC 是覆盖 Claude Code、Codex、Cursor 等工具的技能和钩子合集，11-17 合入一项钩子修复（#3849）：记录 bash 命令时会把裸露的 API key、JWT 和 PEM 私钥打码。垂直技能包这边，Claude-BugHunter 面向漏洞赏金和红队，last30days-skill 做跨平台话题调研，11-17 连发 v4.3.1 和 v4.3.2，新增基于 Exa 的竞品搜索（#1509），Reddit 归档检索失败时改为报告部分结果（#1500）。想挑技能的开发者，可以先看两个大框架的方法论，再按自己的场景挑垂直包。

**主线三：团队引入编码 Agent 的几个环节，各有一个项目在榜。** LoopForge 负责把需求分派给 Claude Code、Codex、CodeBuddy 等编码工具并插入人工审批，11-17 发布 v0.4.0，0.3.9 不再出正式版，装着 v0.3.9-rc.1 的可以直接升级；同期修了 Runner 的 OAuth 刷新协调，并拒绝在沙箱里替换凭据（#1021）。open-code-review 负责代码审查，11-17 发布 v1.13.11，文件读取改为按字节数而不只按行数截断（#1878）。plannotator 是人审阅 Agent 计划和代码的工作台，11-17 发布 v0.28.67，最近合入的 PR 来自 0.29.0 的上手测试（#3605）。cursor/plugins 是 Cursor 的插件规范和官方插件库，最近两天新增 Expensify、Strava、Google Search Console 等第三方插件（#1268、#1267、#1255），收录范围正从开发工具扩到报销、运动、站长工具这类业务服务。

**主线四：AG-UI 和 Univer 连续第四天同榜，AI 科研项目有两个。** AG-UI 是规定 Agent 后端和前端界面如何传递消息、工具调用和状态的开放协议，11-17 新增 Cloudflare Agents 集成（#3365，含破坏性变更），客户端把长对话的推理内容压缩后一次性更新（#3332）。Univer 是可嵌入的表格和文档 SDK，最近合入 XLOOKUP、XMATCH 按字面处理 `?` 和 `*`（#8243），以及 RPC 订阅在取消时释放（#8304）。科研方向，minimind 用约 2 小时从零训练一个 6400 万参数的小模型，是学大模型训练的入门教程，较 09-02 上次在榜多了约 8,900 星；PaperOrchestra 两天里从 1,587 星涨到 3,078 星，但 11-15 之后没有新提交。

**主线五：榜单解读提醒 — 名次和日增对不上，几个项目的星数和关注者落差较大。** superpowers 日增 +1,917 只排 #9，AG-UI +1,445 排 #10，而 last30days-skill +696 排 #2，说明 Trending 的名次并不按当日新增星数排列，读榜时不要把名次当成热度排序。Claude-BugHunter 两天从 6,502 星涨到 9,406 星，subscribers 50，比值约 188:1，open issue 11 个，HN 只有 05-20 一条 1 分的 Show HN；不过近三天仓库合入大量引擎修复，两天前最近的提交还几乎都是机器人刷新 star 曲线图，详情见下文。LoopForge 的比值约 269:1，open-code-review 约 345:1，看待这几个工程项目时需要结合发版和 issue 质量一起判断。
