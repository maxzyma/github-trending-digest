## 新上榜项目

### [elayadesign/ai-design-skills](https://github.com/elayadesign/ai-design-skills) — NEW ⭐ 9,479（+1,395）| Markdown（无主语言）| 信源：中

**它是什么**: 一份写给 AI 编程助手的"设计规范"。你把它装进 Claude Code、Cursor、Codex 或 Windsurf 后，让 AI 做落地页时，AI 会先问你页面结构、转化文案、FAQ 和 SEO 需求，再按文件里规定的字体、间距、圆角、配色、交互状态和动效去写页面。目前只有一个技能 `landing-page-design`。

**解决什么问题**: 不加约束时，AI 生成的落地页常常风格雷同、细节粗糙。这个文件把一套设计偏好写成 AI 能照做的规则，省去每次在提示词里重复交代。安装方式是复制 SKILL.md，或运行 `npx skills add`。

**谁在用、怎么用**（来自 Issues/X）:
- 场景 1: 作者 10-24 在 X 发帖，展示两个月内用 Claude、Cursor 和 Higgsfield 做出的一批落地页，这是目前主要的使用展示。
- 场景 2: 外部开发者提交了改进 PR：#1 加入内容真实性和响应式检查，#6 加 frontmatter 的 CI 校验，#3 补 skills.sh 安装说明，说明有人在实际装用并想扩展它。

**社区怎么评价**:
- 正面: 规则具体、可直接执行，上手成本只有一个文件；外部 PR 集中在补检查项，方向与项目定位一致。
- 负面: #5 指出 B7"动画只允许 transform 和 opacity"与 hover 变色、B11 逐词变色互相矛盾，AI 照字面执行必然违反其中一条。所有 PR 都没有作者回复。
- 健康度: 9,479 stars / 30 subscribers ≈ 316:1；679 forks；5 个 open 项中 4 个是 PR；作者是唯一提交者（8 次）。仓库 7-29 创建后到 10-25 才有第二批提交，10-25 至 10-27 加入的 design-to-motion 已于 10-27 拆到独立仓库。HN、Reddit 无讨论。

**风险与争议**:
- **vanity**: 星数与关注者、讨论量和内容体量不匹配，热度主要来自作者自己的 X 帖。
- **compliance**: 10-26 作者提交"致谢 taste-skill 并改写重叠段落"；据 X 回复（转述），此前 taste-skill 作者公开要求署名。引用或二次分发时注意来源关系。
- **stability**: 规则之间存在冲突（#5），AI 执行结果可能不一致。
- **bus_factor**: 单人维护，外部 PR 全部无人处理。

**技术备注**: 纯 Markdown，MIT 许可，目录为 `skills/` 下的 SKILL.md；可通过 skills.sh 生态安装。

### [togg53192-cmd/jailbreaks](https://github.com/togg53192-cmd/jailbreaks) — NEW ⭐ 5,624（+902）| Markdown（无主语言）| 信源：中

**它是什么**: 一个收集大模型"越狱"提示词的资料库。越狱指用特制的系统提示或人设设定，诱导模型绕开厂商设置的安全限制。仓库根目录约 38 个文件，基本一个模型一份，覆盖 Claude、Gemini、Grok、Mistral 等闭源模型，DeepSeek、Qwen、Kimi、GLM、Gemma 等开源权重模型，以及 OpenCode 上的免费模型；部分做成 AGENTS.md 或 Ollama Modelfile，直接放进编程 Agent 使用。

**解决什么问题**: 它面向想让模型回答被拒问题的用户，把零散流传的提示整理成按模型分类的合集，并随模型更新跟进。

**谁在用、怎么用**（来自 Issues/X）:
- 场景 1: 用户按模型取用并反馈失效，例如 #5（Muse 上不起作用，6 条评论）、#8（Spacebunny 不起作用，已关闭）、#15（DeepSeek 4.1 以版权为由拒绝下载种子）。
- 场景 2: 用户点名求新模型版本，例如 #22 请求 Nemotron 3 系列；据 X 搜索，9 月 27 日有两个账号发布写法相近的帖子，介绍把 DeepSeek V4.1 版本放进 OpenCode 当 AGENTS.md 使用（转述，浏览量未核实）。

**社区怎么评价**:
- 正面: 更新频繁，9 月初到 10-25 每隔几天就有提交，作者会在 issue 里回应失效报告。
- 负面: 多个 issue 报告失效；作者对 #5 的解释是外部分类器拦截，而非提示本身失效，用户无法独立验证。
- 健康度: 5,624 stars / 68 subscribers ≈ 83:1；831 forks，fork 比例偏高，符合"复制拿去用"的特征；14 个 open issues；作者 69 次提交，另外 3 名贡献者合计 9 次。仓库无 license。HN、Reddit 无讨论。

**风险与争议**:
- **compliance**: 内容用于绕过模型安全限制，违反主流模型厂商的使用条款；在工作或产品环境使用可能导致账号封禁，仓库本身也有被下架的风险。
- **stability**: 模型更新或厂商加装分类器后提示就会失效，issue 里已有多起失效报告。
- **bus_factor**: 基本由作者一人维护，作者账号无公开身份信息。
- **安全研究参考价值有限**: 没有测试方法和成功率记录，做红队或安全评估的团队不能把它当作可复现的基准。

**技术备注**: 纯 Markdown 与配置文件，含 Ollama Modelfile、Grok 配置和 AGENTS.md 工作区策略；无代码、无 license。
