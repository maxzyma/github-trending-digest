## NEW 首次上榜

### [makecindy/cindy](https://github.com/makecindy/cindy) — NEW ⭐ 4,126（+477）| TypeScript | 信源：中

**它是什么**: 一个装在电脑和手机上的 AI 助手客户端。它本身不是新的编程 Agent，而是把 Claude Code、Codex 这些现成的 Agent 放进同一个工作区：一个任务做到一半可以换模型或换 Agent，记忆和技能（Skill）在不同 Agent 之间共用。它还能操作浏览器、电脑和手机，可以从聊天工具或定时任务接活。出品方是游戏公司心动（XD），CEO 黄一孟在 7-26 的 TDW 2026 上发布，他本人是仓库提交最多的作者。

**解决什么问题**: 同时用 Claude Code 和 Codex 的开发者，以前要在不同终端和订阅之间切换，会话和记忆各管各的，离开电脑就没法续上。Cindy 把订阅、会话和记忆收进一个客户端，手机上也能接着看和推进任务。模型可以走官方云服务按量付费、复用已付费的 Claude Code / Codex 订阅、自带 API Key，或用本地模型。

**谁在用、怎么用**（来自 GitHub Issues 与中文社区）:
- 远程开发：有用户通过 SSH 连远程 DGX Spark 机器时遇到模型不可用、检测不到 Codex CLI（#4286）。
- 长会话与多 Agent 协作：会话中图片过大后报 413 错误，整条会话无法恢复（#7075）；派发出去的 Worker 可能无输出就结束（#3098），手机端看不到 Worker 列表和进度（#4395）。
- 日常使用：LINUX DO 帖子的用户看重国内直连速度快、手机端同步快、能复用已有订阅；也有人用内置的 TapTap 制造做游戏创作。

**社区怎么评价**:
- 正面: 发布约 3 个月，版本几乎每天一版（10-23 为 v0.1.115），贡献者 147 人；中文社区评价交互花了心思，复用订阅这一点实用。
- 负面: Windows 上被后台插件抢焦点（#500，16 条评论）；知乎作者提到排版错乱和界面卡死；有用户不满 `.mindfs` 目录放在项目里、需要手机号登录、官网付费说明不清；有博客担心跨项目记忆互相干扰。黄一孟在 X 上自己也说它“纯 Vibe 出来”“还有很多不完善”。
- 健康度: 4,126 stars / 17 subscribers，约 243:1；597 forks。开放 issue 约 1,587 个、开放 PR 约 300 个，累计 3,132 个 issue 中 1,234 个带 bug 标签，大量由团队成员和机器人账号提交。前 4 名提交者都在公司内部，约占前 10 人提交量的 81%。HN、Reddit 无讨论，X 上主要是作者和官方账号在推。

**风险与争议**:
- **dependency**: 只开源客户端，后端不开源，默认连接官方云服务和官方更新源；跳过登录只能用本地 Agent 部分。
- **privacy**: 客户端可操作本机文件、浏览器和已登录的应用，默认连官方服务器，接入前要看清哪些数据会上传。
- **stability**: v0.1.x 阶段，bug 类 issue 上千，会话无法恢复（#7075）、Worker 静默结束（#3098）仍未关闭。
- **cost**: 官方托管模型按量计费，另有付费方案，价格说明不够清楚。
- **bus_factor**: 核心开发集中在公司内部 4 人，项目走向取决于心动的产品策略。

**技术备注**: TypeScript；桌面端 Electron，手机端 Expo；接入 Claude Code、Codex 等外部 Agent CLI；官网 cindy.app。

### [jbiaojerry/ebook-treasure-chest](https://github.com/jbiaojerry/ebook-treasure-chest) — NEW ⭐ 22,651（+227）| Python | 信源：中

**它是什么**: 一份按 1,000 个标签分类的中文电子书下载目录，约 24,071 本书，每本列出书名、作者和 epub / mobi / azw3 下载链接，另有一个网页搜索页。仓库本身不存书，链接全部指向城通网盘的同一个账号。Python 代码是爬虫加页面生成器：抓取 dushupai.com 的书籍页面，取出网盘链接，生成分类文件和 `books.json`。

**解决什么问题**: 想找某本书电子版的读者，不用逐个网站搜，可以在一个目录里按分类或书名查。README 说覆盖了帆书（原樊登读书）、微信读书、京东读书、喜马拉雅等平台的大部分书目。

**谁在用、怎么用**（来自 GitHub Issues）:
- 下载体验：多位用户反映网盘广告多、限速严重（#20、#30），有人说“每个文件都是广告”（#27），其他用户回复点“普通下载”即可；作者在 #20 回复“你们赞助一下？”。
- 维护方式：2024 年用户反映需要提取码（#1），作者 10-31 回复已全部改为免密；有人建议把书提交到 LibGen 或 Anna's Archive，“不用担心被端”（#28）。其余多是求书 issue（#2、#12、#29）。

**社区怎么评价**:
- 正面: 覆盖面大，分类细，有搜索页。
- 负面: 下载要经过广告和限速的网盘，链接会失效。
- 健康度: 22,651 stars / 160 subscribers，约 141:1；3,194 forks，6 个 open issue。仓库建于 2023-09-13，最后推送是 2026-01-13，此后无提交，这次上榜没有对应的新版本或事件。作者提交 52 次，其余是自动化机器人。HN、X、Reddit、V2EX、知乎均未找到讨论，外部只有一篇资源博客介绍（2025-06-24）。

**风险与争议**:
- **compliance**: 收录了大量仍在版权期内的商业图书，链接指向的网盘按下载量给上传者分成；每个分类页的“仅供宽带测试，24 小时内删除”声明不改变侵权性质。作者另一个仓库曾出现在 2020 年出版社的 DMCA 下架通知中。
- **dependency**: 依赖 dushupai.com 和城通网盘，任一方变化都会让链接成批失效。
- **vanity**: 停更 9 个月后回榜，外部讨论为零，热度来源不明。
- **bus_factor**: 作者一人维护。

**技术备注**: Python 爬虫 + GitHub Actions 定时同步（设定每天 02:00 运行，1 月后无新提交）+ GitHub Pages 搜索页；代码本身对做“目录站生成器”有参考价值，内容不适合引用或传播。

**它是什么**: 一只约 25 厘米高、不到 800 克的双足“小鸭”机器人的控制软件。机器人能走路、坐下、摔倒后自己爬起来、用嘴叼东西、踢球。出品方 Pollen Robotics 属于 Hugging Face，由 Seeed 代工，8-27 开放预订，售价 399 美元。这个仓库是它的“大脑”：一组 Rust 程序跑在机器人的 RK3566 主板上，每秒 50 次运行神经网络策略，驱动 15 个舵机。策略在姊妹仓 `microduck_rl`（8-31、9-01 曾在榜，现约 2,600 星）里用仿真训练后导出。

**解决什么问题**: 想动手做“具身智能”（让 AI 控制真实机器人）的开发者，以前要么买几千美元的研究平台，要么从零搭硬件和训练流程。Microduck 给出一台几百美元的整机，加上从仿真训练到真机部署的完整软件链，可以在桌面上实验步态策略。

**谁在用、怎么用**（来自 GitHub Issues 与 HN）:
- 二次开发：有人做第三方客户端（#329），多人想加双向语音做成对话助手（#215），社区已有 awesome-microduck 资源列表。

- 复刻：社区要求开源 3D 打印件，官方明确只开源软件（#168、#173）；中国大陆不在发货范围（#182），评论区提到国内已有团队在复刻。

**社区怎么评价**:

- 负面: 有人在 #168 评论“打着开源旗号卖货”；配对 PIN 可被同机其他后台程序读取（#233）。
- 健康度: 11,025 stars / 72 subscribers，约 153:1；1,415 forks，issue 共 50 个、19 个未关闭。仓库建于 7-29。两位作者提交约占前 10 名的 92%。这次上榜没有找到单一触发事件，可能与 10 月中旬的连续发版有关（推断）。

**风险与争议**:
- **compliance**: 宣传为开源机器人，但开源的只有软件，硬件设计和打印件不公开（#168）。
- **dependency**: 只能运行在官方硬件上，大陆买不到（#182），新订单交付已排到圣诞之后。

**技术备注**: Rust 守护进程运行在 RK3566 上；15 个 XL330 舵机；策略用 MuJoCo + PPO 训练，导出 ONNX 部署。
