## 新上榜项目

### [expo/skills](https://github.com/expo/skills) — NEW ⭐ 3,609（+90）| Shell | 信源：中

**它是什么**: Expo 是用 React Native 开发手机 App 的主流框架。这个仓库是 Expo 官方写给 AI 编程助手的"使用手册"，共 24 个技能。装上以后，你让 Claude Code、Codex 或 Cursor 做 Expo 项目，AI 会按官方推荐的写法处理路由、动画、原生界面、SDK 升级，以及上架应用商店、发热更新、在云模拟器上复现 bug。

**解决什么问题**: AI 助手对 Expo 的了解常常停留在旧版本，写出的代码用过时的 API 或不符合官方推荐。以前开发者要自己在提示词里贴文档；现在装一个插件，AI 就能按当前版本的官方写法做事。入口技能 `expo-overview` 先判断该用哪个技能，避免全部技能同时占用上下文。

**谁在用、怎么用**（来自 Issues/X/官方博客）:
- 场景 1: 用户把它装进 Claude Code 和 Cursor 做日常开发，并报告安装问题，例如 Cursor 安装失败（#41）、APM 无法安装（#172）、eval-harness 子模块导致 Claude Code 插件市场匿名克隆失败（#110）。
- 场景 2: 用户在意上下文开销，#86 提出十几个技能常驻上下文太占 token，建议改成路由技能；团队随后加了 `expo-overview` 入口（#107）。
- 场景 3: 官方博客演示让 Agent 在 EAS 云模拟器上复现 bug 并提交修复 PR；据 Expo 官方 X 帖，加装技能后原生 UI 写法在内部评测中提升 46%（官方自述，未见独立复现）。

**社区怎么评价**:
- 正面: 官方维护、更新频繁，近几天集中提交云模拟器（#256–#258、#262）和 Agent 工作流技能（#265）；安装渠道覆盖 Claude Code、Codex 和 `npx skills`。
- 负面: 多客户端安装兼容问题仍在；部分 issue 是无内容的灌水帖。
- 健康度: 3,609 stars / 21 subscribers ≈ 172:1，官方组织仓库关注者偏少较常见，不宜单凭比值判断；229 forks；约 100 个 open 项，其中 75 个是 PR；主要提交者是 Expo 团队成员；2025-11-30 创建，10-28 仍有推送。HN 只在一条周刊评论里被顺带提到，X 上以官方和团队成员推广为主，Reddit 未能核实。

**风险与争议**:
- **dependency**: `eas-*` 技能围绕付费的 EAS 服务，云模拟器目前需要申请排队，不用 EAS 的团队只能用到一半内容。
- **cost**: 技能描述会进入 AI 助手的上下文，装得多会增加 token 消耗（#86）。
- **privacy**: 已合入匿名用量统计和技能反馈功能（#71），另有自动提交反馈的 PR 待审（#112），在公司环境使用前确认上报内容。
- **stability**: 不同客户端的安装和更新仍有兼容问题（#41、#93、#172）。

**技术备注**: Markdown 技能文件加 Shell 脚本，MIT 许可；可通过 `claude plugin install expo@claude-plugins-official`、`codex plugin add expo@openai-curated` 或 `npx skills add expo/skills` 安装。

### [xiaolai/the-craft-of-selfteaching](https://github.com/xiaolai/the-craft-of-selfteaching) — NEW ⭐ 18,544（+148）| Jupyter Notebook | 信源：中

**它是什么**: 李笑来写的开源书《自学是门手艺》。前半部分讲怎么自学（学、练、用、造），后半部分用 Python 入门当练习对象，从值和运算符讲到函数、字符串、正则、装饰器和生成器。全书以 Jupyter Notebook 发布，读者可以边读边运行代码。2019 年出版过纸质书。

**解决什么问题**: 它面向想自学编程但不知道从哪开始的中文读者，把"怎么学"和"学什么"放在同一本书里，读完方法论马上就有一门语言可练。

**谁在用、怎么用**（来自 Issues/中文社区）:
- 场景 1: 读者在本地或在线 Jupyter 环境里跟着书运行代码，并在 issue 里汇总环境问题，例如 #143 专门收集 Windows 下的运行问题。
- 场景 2: 读者逐章纠错和提建议，例如 #1011 指出 `divmod` 返回值的说明有误，#624 对正则章节提出修改。
- 场景 3: 17,889 个 fork 与星数几乎相当，符合"fork 一份到自己账号里读"的用法（推断）。

**社区怎么评价**:
- 正面: 豆瓣上一部分读者认为方法论部分有启发。
- 负面: 另一部分读者认为它作为 Python 入门书不够严谨，说教内容偏多；#818 等 issue 质疑书中的部分事实陈述。
- 健康度: 18,544 stars / 717 watchers ≈ 26:1；15 个 open issues，185 个 PR 长期未处理；最近提交是 2026-05-20 作者本人改 JupyterLab 配置说明。10 月没有提交，也没找到新版、译本或报道，回榜触发事件不明。HN、X、Reddit 无讨论，中文讨论集中在豆瓣和知乎。

**风险与争议**:
- **stability**: 内容按 Python 3.6 时代写成，部分示例和环境说明与当前 Python、JupyterLab 版本有差距，跟着学时需要自行对照新版本。
- **bus_factor**: 作者一人维护，大量 PR 积压，纠错难以合入。
- **compliance**: 采用 CC BY-NC-ND 3.0 许可，不允许商用和改编；培训机构或企业内训想改编使用需另行授权。

**技术备注**: Jupyter Notebook 加 Markdown，依赖本地 Python 与 JupyterLab 环境。
