## 首次上榜项目

### [morluto/rea](https://github.com/morluto/rea) — NEW ⭐ 9,628（+2,956）| TypeScript | 信源：中

**它是什么**: 一个给 AI 编程助手用的"逆向分析工具箱"。装好后，你可以直接对 Claude Code、Codex 等助手说"看看这个 App 的某个功能是怎么做的"，它会调用反编译器、抓包和代码分析工具去拆解目标程序，再给出带证据的结论。

**解决什么问题**: 逆向一个应用通常要会用 Ghidra、IDA 这类专业工具，还要懂汇编、文件格式和调试技巧，门槛很高。`rea` 把这些工具注册成 agent 可调用的能力（MCP Server + CLI，npm 包名 `rea-agents`），一条 `npx rea-agents setup` 就能接入十余种 agent。可分析原生二进制、JS/Electron/ASAR 包、.NET 程序、网站和浏览器抓包、APK（需另装 JADX）和固件（需另装 Binwalk/Unblob）。分析在本地运行，输出附证据和局限说明。

**谁在用、怎么用**（来自 Issues/X）:
- Windows 用户试装：Ghidra 分析在 Windows 上被硬性关闭，与 README 宣传的 Windows 支持矛盾（#527，已修）；另有 setup/doctor 报错（#504、#526）和 ASAR 路径分隔符问题（#570）。
- 分析大型 Electron 应用：大目标报 `RangeError`（#623），24 MB 的 Obsidian ASAR 跑几分钟无输出后失败（#746），两者仍未关闭。
- 接入不同模型：有工具的参数 schema 被 Anthropic API 拒绝（#528，已修）；有人希望支持 .NET NativeAOT 程序反编译（#744）。

**社区怎么评价**:
- 正面: 维护响应快，10-05 以来的外部 issue 不少已在一两天内修复关闭；fork 1,066 个，约占 stars 的 11%，比同类高热度项目更像有人在实际使用。
- 负面: 未找到独立开发者的实测好评；X 上的传播主要来自 AI 推介账号（10-04、10-05 两条帖子）；HN 有 7 月一条 Show HN（3 分）和 10-06 一条（1 分），均无评论；Reddit 无讨论。
- 健康度: 9,628 ⭐ / 30 subscribers（约 321:1）/ 1,066 forks / 107 open（含 PR，累计约 348 个 issue、462 个 PR）。4-14 建仓，10-06 仍有推送。累计约 1,057 次提交，作者约 695 次（约 66%），另有三位贡献者分别约 196、74、53 次。

**风险与争议**:
- **compliance**: 主打"复刻别人 App 的功能"，可能违反目标软件的 EULA 或反逆向条款，涉及著作权；Hopper、IDA 本身也需要授权。
- **stability**: Windows 支持仍属实验性，大体积应用分析会失败（#623、#746）。
- **security**: 推荐安装方式是 `curl | bash`；工具本身要处理不可信的二进制和应用包。
- **bus_factor**: 约三分之二的提交来自作者一人，但已有几位稳定贡献者。
- **vanity**: 程度中等。比例高、HN/Reddit 几乎没有讨论，但 fork 数和近两天的外部 issue 是真实使用的信号。

**技术备注**: TypeScript，MIT；MCP Server + CLI；支持 macOS、Linux，npm 4.1.0 起实验性支持 Windows x64；深度原生分析需 Hopper（可用演示模式）、Ghidra 或 IDA Pro 之一，静态 JS 分析不依赖这些引擎。
