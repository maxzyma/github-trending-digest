## 首次上榜项目

### [cloudflare/cloudflare-os](https://github.com/cloudflare/cloudflare-os) — NEW ⭐ 10,580（+85）| TypeScript | 信源：强

**它是什么**: Cloudflare 自己公司里人人在用的"AI 工作台"，现在开源了。员工打开浏览器，跟 agent 对话，让它写文档、做幻灯片、搭数据看板、写自动化脚本，或者做一个给同事用的小应用（项目里叫 Gadget）。每个人的应用各跑在一个独立沙箱里，agent 默认什么外部系统都碰不到，要访问公司系统时得经过一个叫 Gatekeeper 的关口逐项授权。

**解决什么问题**: 公司想让员工普遍用上 agent，常见做法是给每人开一个聊天助手订阅，但这样很难让 agent 安全地接触公司内部数据，做出来的小工具也散落在个人电脑上。`cloudflare-os` 把 agent、应用托管和权限管理放进同一个平台：数据接入按需授权，做好的应用可以直接分享给同事。设计思路沿用作者 Kenton Varda 早年 Sandstorm.io 的权限模型，改为跑在 Cloudflare Workers 上。

**谁在用、怎么用**（来自 Issues/HN/X/官方博客）:
- Cloudflare 内部：官方博客称 2026 年 5 月起全员使用，包括非工程岗，用来做幻灯片、文档、看板和自动化；10 月博客自称已有数千个组织在用，此数字无独立来源核实。
- 自托管团队：外部开发者提交了实质性 PR，如批量操作时逐条否决（#528，34 条评论）、导出 docx（#439）、接入 GitLab 授权（#531）。
- 部署障碍：免费套餐跑不起来（#9，已关闭）、本地启动失败（#19、#443）、agent 长任务超出 Worker CPU 时间限制（#603）。

**社区怎么评价**:
- 正面: HN 主帖 668 分、330 条评论，认可逐项授权的权限模型、可自托管，作者在讨论区亲自答疑。
- 负面: HN 上不少人认为叫 "OS" 名不副实，担心深度绑定 Cloudflare；也有人质疑 workerd 不算加固过的沙箱，安全宣称偏强。X 上的声音以 Cloudflare 官方、CTO 和员工为主，独立开发者的使用反馈较少。Reddit 未找到讨论。
- 健康度: 10,580 ⭐ / 41 subscribers（258:1）/ 1,283 forks / 128 open（约一半是 PR）。4-15 建仓，今天仍有推送。提交高度集中在 kentonv 一人，其余为一批 Cloudflare 员工。

**风险与争议**:
- **stability**: README 自述处于 early access 阶段，本地启动和长任务都有未解决问题（#603、#443）。
- **cost**: 长连接会让 Durable Objects 一直计费（#338），免费套餐无法运行，自托管成本需要提前评估。
- **dependency**: 深度依赖 Workers、Durable Objects 和 workerd，迁出 Cloudflare 的成本高。
- **bus_factor**: 核心提交集中在单一作者，但有公司团队维护。

**技术备注**: TypeScript，部署在 Cloudflare Workers + Durable Objects 上；Apache-2.0；10-01 起另有官方托管版本可申请。

### [meituan-longcat/LongCat-Video](https://github.com/meituan-longcat/LongCat-Video) — NEW ⭐ 8,758（+44）| Python | 信源：中

**它是什么**: 美团 LongCat 团队开源的视频生成模型，136 亿参数。一个模型能做三件事：根据文字生成视频、根据一张图片生成视频、把已有视频接着往下续写。主打能生成几分钟长的 720p、30 帧视频，越往后画面也不容易跑色或变糊。后来推出的衍生版 Avatar 可以用一张照片加一段音频生成对口型的说话视频。

**解决什么问题**: 多数开源视频模型只能生成几秒钟片段，想要长视频得自己拼接，衔接处容易断裂。LongCat-Video 把续写作为原生能力，适合需要连续画面的场景；代码和权重都是 MIT 许可，可以商用和自行部署，不必依赖付费的闭源视频服务。

**谁在用、怎么用**（来自 Issues/X/第三方集成）:
- 数字人口播与带货视频：X 上中文技术博主集中推荐 Avatar 1.5（5-21 发布，推理只需 8 步）的口型同步效果。
- 本地部署：社区通过 Kijai 转换的权重在 ComfyUI 中运行，LocalAI 也把它接成视频生成后端，fal.ai 提供托管调用。
- 实际故障：48G 显存仍提示显存不足（#79，15 条评论）、v1.5 表情和动作过度（#120）、开启蒸馏后嘴唇越来越红（#113）。

**社区怎么评价**:
- 正面: 长视频稳定性和 MIT 许可受到关注，Hugging Face 员工在 X 上转发了初版发布。
- 负面: 显存门槛高，多卡运行有问题；HN 只有 3 个帖子，最高 3 分；Reddit 未检索到讨论。X 上 7 月后有营销式推文，独立实测反馈很少。
- 健康度: 8,758 ⭐ / 87 subscribers（101:1）/ 1,526 forks / 80 open issues，7 位贡献者、提交集中在前两位。2025-10-25 建仓，最后推送 2026-05-27，GitHub 仓库描述为空。

**风险与争议**:
- **stability**: 显存需求高，多卡运行失败，v1.5 存在表情过度等质量回归（#120、#113）。
- **bus_factor**: 贡献者集中，5-27 之后没有推送。
- **vanity**: 程度较轻。今天上榜找不到对应的版本或提交，热度与近期活跃度不匹配；但 101:1 的比例本身正常。

**技术备注**: Python + PyTorch，13.6B 参数，基于扩散 Transformer；论文 arXiv 2510.22200；ComfyUI 暂无官方节点。
