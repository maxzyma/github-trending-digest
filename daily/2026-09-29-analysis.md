## 首次上榜项目

### [cs341-illinois/coursebook](https://github.com/cs341-illinois/coursebook) — NEW ⭐ 2,540（+195）| TeX | 信源：中

**它是什么**: 伊利诺伊大学香槟分校（UIUC）"系统编程"课 CS 341（旧编号 CS 241）的官方开源教材。内容从 C 语言讲起，一路讲到进程、线程、同步、内存分配、网络和文件系统，可以在线读，也可以下载 PDF。

**解决什么问题**: 系统编程的经典教材大多是付费书，或者偏理论、离动手写代码较远。这本教材由课程组按实际授课内容编写，配合作业讲"怎么用 C 和 POSIX 接口写出正确的并发与系统程序"，免费公开，课外自学者也能直接用。在线版在 cs341.cs.illinois.edu/coursebook，课程资源页把它列为指定读物。

**谁在用、怎么用**（来自 Issues/HN）:
- 课程学生与助教：9 月有一轮集中修订，#239 重画了 6 张与正文矛盾的插图，#240 改写了 10 处表述不清的句子，都是按复审意见逐条处理。
- 读者纠错：#181 指出 PDF 版 C 内存模型图有误，#186 质疑条件变量链表示例的写法，说明有人逐行在读、在跑。
- 无障碍与多格式阅读：#248（9-28 新开）在推插图 alt text 进入 EPUB 与 wiki 版本，并加 CI 检查。
- 自学读者：HN 2020-04 的"Free System Programming Textbook (Illinois CS241)"帖 257 分，是它最主要的一次外部曝光。

**社区怎么评价**:
- 正面: 课程组持续维护，9 月有实质性的内容修订；HN 旧帖评价它是少见的免费、贴近实践的系统编程读物。
- 负面: #181、#186 等 2020–2021 年的勘误至今未关，#59（补面试题）、#79（重排章节目录）这类老需求长期搁置；README 与侧栏里一度残留旧组织名 illinois-cs241 的链接（#243、#245，已由 #244 修复）。
- 健康度: 2,540 stars / 48 subscribers（53:1），46 个 open issues 多为旧积压；仓库 2018-01 创建，最后推送 9-26。历史提交集中在两位作者（471 次与 83 次），9 月的合并基本由课程教师一人完成。近期 HN、X、Reddit 均未检索到新讨论。

**风险与争议**:
- **bus_factor**: 维护基本依赖课程教师一人，学期之外可能长期无人处理 issue。
- **stability**: 旧勘误积压，部分图示与正文可能仍不一致，阅读时以最新在线版为准。
- **compliance**: GitHub 显示"无 license"是因为许可文件放在 `LICENSE/` 目录下未被识别；实际分为代码（`LICENSE.code`）、生成的 PDF 等产物（`LICENSE.output`）和原始 wikibook（`LICENSE.original`）三份，转载或再分发前需按对应许可署名。

**技术备注**: LaTeX 源码，构建输出 PDF、EPUB 与网页版；今天上榜的直接诱因未找到外部信源，推断与美国秋季学期授课和 9 月中旬的集中修订有关。
