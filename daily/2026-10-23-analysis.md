**主线二：PHP 安全事件 — 两个 CVSS 10.0 的远程代码执行漏洞把 php-src 推上榜首。** PHP 团队 10-21 同时发布 8.5.12、8.4.27、8.3.36、8.2.35，修复 CVE-2026-109618 与 CVE-2026-109619。发布说明称两者都允许未认证的远程代码执行，“没有完整的缓解手段，升级是唯一安全选择”。第一个漏洞出在内存耗尽处理：多段（multipart）请求可以在不超出表面限制的情况下耗尽内存，使请求内存停在未初始化状态，随后被关闭流程读取（GHSA-w8hw-w9fx-j79w）。第二个是常驻工作进程在两次请求之间残留全局状态，导致释放后重用（GHSA-6wmf-4rv5-p3rp）。HN 上的讨论很集中：PHP 官方安全公告 1,555 分、658 条评论，PHP 8.2.35 发布帖 1,096 分，PHP 基金会解释此次修复与后续安全投入的文章 811 分；另有帖子报告 openwrt.org 因此临时下线。修复提交约 1.15 万行（HN 上有专帖讨论提交规模）。php-src 今天只涨 287 星，排第 1 不是靠星数，而是事件带来的集中关注。对运维 PHP 服务的读者，这条比榜上任何新项目都更需要立即处理。

**主线三：PCL 上榜是一次合规事件，不是新项目走红。** PCL 10-20 发布 2.99.0.0，更新说明是“为遵守相关法律法规，PCL 不再提供 MC 下载功能”。源码里用一个开关屏蔽了游戏版本下载和整合包安装，已安装的游戏和 Mod 下载不受影响。随后 GitHub 上出现多个恢复下载功能的 fork 和补丁，社区版 PCL-CE 据报道也跟进限制（转述未验）。中文社区讨论很多，HN、Reddit 没有讨论。它和 FastAPI、Supabase 一样是老仓库，上榜反映的是事件关注度，不代表新用户在增长。

### [Meloong-Git/PCL](https://github.com/Meloong-Git/PCL) — NEW ⭐ 9,052（+119）| Visual Basic .NET | 信源：中

**它是什么**: PCL（Plain Craft Launcher）是一款 Windows 上的 Minecraft 启动器，在国内玩家中使用很广。它负责下载和安装不同版本的游戏、管理 Mod 和整合包、处理登录，然后启动游戏。作者是龙腾猫跃（GitHub 账号 LTCatt）。

**解决什么问题**: 官方启动器在国内下载慢，对 Mod、整合包和多版本共存的支持也不方便。PCL 把下载加速、Mod 资源检索、整合包一键安装和主题自定义集中在一个中文界面里，玩家不需要手动拼装文件。

**谁在用、怎么用**（来自 Issues/中文社区）:
- 本地化与配置：#4145 讨论语言、配置项和时间格式的本地化，175 条评论，是仓库里讨论最多的 issue。
- 安装与解压：#7556 用户用 Windows 自带解压工具解压后启动器打不开（30 条评论）。
- 下载功能关闭后：事件后几天新增 issue 很密集，例如 #9533 Java 下载列表失败后抛异常、#9532 主页内容加载失败（转述未验）。
- 中文社区：MineBBS、NexusMC 论坛、B 站都有专门讨论下载功能关闭的帖子，GitHub 上也有人建了事件梳理仓库（转述未验）。

**社区怎么评价**:
- 正面: 长期功能需求活跃，社区持续提交修复，日常 PR 由维护者 HerobrineXia 合并。
- 负面: 关闭游戏下载后不满集中，多个恢复下载功能的 fork 和补丁随即出现。
- 健康度: 9,052 星、34 个 subscribers，比值约 266:1；1,346 fork，open issue 287。仓库 2022-07 创建，已有 4 年多，下载用户多、开发参与者少的启动器类项目比值普遍偏高，不能据此判断热度失真。正式版本只由作者 LTCat 一人提交发布（10-16 发布 2.14.0.0，10-20 发布 2.99.0.0）。HN、Reddit 均无相关讨论，讨论集中在中文社区。

**风险与争议**:
- **compliance**: 许可证不是开源许可，而是作者自定义的分发许可（GitHub 显示 NOASSERTION），恢复下载功能的 fork 是否被允许存在疑问；下载功能关闭本身也是作者以合规为由做出的决定。
- **dependency**: 核心的游戏下载功能可能随监管要求下线，同类启动器也受同一环境影响。
- **bus_factor**: 正式版本只由作者一人发布，下载限制这类决定没有其他维护者能改变。

**技术备注**: VB.NET + WPF，仅支持 Windows。仓库公开大部分源码，随版本同步更新；GitHub Releases 接口为空，版本以提交记录为准。下载限制由源码中的 `RestrictMcDownload` 开关实现，涉及下载安装页和整合包模块。
