**主线二：Agent 生成的代码由谁来审，今天榜上有三种做法。** Open Code Review 把确定性规则流水线和 LLM Agent 拼在一起，按行给出评论，11-12、11-13 连发 v1.13.8 和 v1.13.9；它从 10-10 上次在榜时的 45,283 星涨到 50,662 星。Codex Security 走的是安全扫描路线：找漏洞、验证、再出补丁，11-13 补了 Deep Scan 预检沙箱限制的说明，还加了一组合成的安全工作流基准。Plannotator 把审查交还给人：Agent 出计划或 diff 时弹出一个网页，你像批注文档一样圈改，再一键把意见送回 Agent。Modern Web Guidance 和 chrome-devtools-mcp 则在写代码这一侧补知识和调试手段，前者今天又加了 11 条 JavaScript 分析规则。如果你的团队已经在用 Agent 写代码，可以按"机器规则、安全扫描、人工批注"三层对照这几个项目，看自己缺哪一层。

## 新上榜项目

### [backnotprop/plannotator](https://github.com/backnotprop/plannotator) — NEW ⭐ 10,480（+108）| TypeScript | 信源：中

**它是什么**: 一个给 AI 编程 Agent 用的本地审阅界面。Agent 写出计划、HTML 页面或代码改动时，浏览器里自动弹出一个页面，你可以像在文档里批注那样圈出段落、写评论，最后一键把所有意见送回 Agent，让它照着改。它支持 Claude Code、Codex、Copilot CLI、Gemini CLI、OpenCode、Kiro、Amp 等十来种 Agent，后来又加了 GitHub PR / GitLab MR 审查和一个汇总多 Agent 待决事项的 Inbox。

**解决什么问题**: 以前审 Agent 的计划只能在终端里读一大段文字，再手打一段回复说"第 3 步不对、第 5 步改成……"，意见容易漏、Agent 也容易误读。Plannotator 让你直接在原文对应位置批注，反馈带着位置信息回到 Agent。

**谁在用、怎么用**（来自 Issues/HN/X）:
- 审 plan mode 计划: Claude Code 用户在计划阶段批注后让 Agent 修订，这是项目最初的用法；Show HN（2026-06，5 分 2 评）就是这个版本。
- 同时管多个 Agent: #2593 是一位用户的报告，Inbox 积累大量记录后浏览器标签占用 1.6 GB 内存，说明有人在长期、多 Agent 地使用 Inbox。
- 持续审查会话: #1116（6 条评论）请求支持实时更新、Agent 可以直接回复批注的持续会话。
- 终端集成: cmux 内置了对 Plannotator 的支持；Pi 作者 Mario Zechner 在 X 上说要用它做大重构（转述，帖子原文未逐条核对）。

**社区怎么评价**:
- 正面: X 上有几位独立开发者给出好评，有人把它称为"理想的本地代码审查工具"。
- 负面: 大数据量下的内存占用（#2593）；PR 审查希望支持更多平台和双向评论线程（#1583）。
- 健康度: stars/subscribers 约 437:1，比值偏高，但 787 个 fork、210 个 open issue（含 PR）和三天三个版本（最新 v0.28.64，11-13）说明在被真实使用。贡献高度集中：作者 8,237 次提交，第二名 24 次。

**风险与争议**:
- **bus_factor**: 几乎全部提交来自一位作者。
- **stability**: 版本号还在 0.28.x，迭代很快，Inbox 存在大数据量内存问题（#2593）。
- **vanity**: 外部声量以官方 X 账号发布为主，HN 帖子分数都在个位数，Reddit 未找到讨论。

**技术备注**: TypeScript，Apache-2.0，2025-12-28 建仓。通过各 Agent 的 hook 或插件机制接入，本地起网页服务；分享链接走压缩 URL。

### [tradermonty/claude-trading-skills](https://github.com/tradermonty/claude-trading-skills) — NEW ⭐ 4,197（+69）| Python | 信源：中

**它是什么**: 一套给股票投资者用的 Claude Skill 合集，大约 70 多个。装进 Claude Code 后，你可以让 Claude 看大盘宽度、判断现在该持多少仓、筛选形态合适的候选股、计算单笔仓位、记交易日志、做事后复盘。它不替你下单，也不提供荐股信号。

**解决什么问题**: 个人交易者通常要在行情网站、筛选器、表格和笔记之间来回切换，纪律也全靠自觉。这个项目把"先看环境、再筛股、再算仓位、交易后复盘"做成固定流程，还有 drawdown-circuit-breaker、pre-trade-discipline-gate 这类在回撤或冲动交易前拦一下的技能。

**谁在用、怎么用**（来自 Issues/README）:
- 每日环境判断: README 给出的典型用法是每天花 15 分钟跑 market-breadth-analyzer、exposure-coach，决定当天仓位暴露。
- 免费档用户: #707 报告新注册的 FMP Basic key 调用多个技能返回 402/403，说明不少人在免费档上尝试。
- 作者自用路线图: #332（P0，行情数据源契约测试和定时 canary）、#297 等高评论 issue 基本是作者按优先级写给自己的任务。

**社区怎么评价**:
- 正面: Skill 目录站和几个 X 账号做了推荐转发（转述，帖子原文未核对）。
- 负面: 缺少 API key 时直接抛出未捕获异常；免费档说明过时（#707）。
- 健康度: stars/subscribers 约 100:1；已关闭 PR 约 480 个，主分支几乎每天有提交，作者贡献 411 次，其余主要是 dependabot。HN 和 Reddit 均未找到讨论。

**风险与争议**:
- **cost**: 核心筛选依赖付费的 FMP 行情 API，部分功能还需要 FINVIZ 付费档（README 提到每月 39.5 美元）。
- **compliance**: README 写明不构成投资建议，但输出仍是 AI 生成的分析，用于真实交易时风险由使用者承担。
- **bus_factor**: 维护基本由作者一人完成。
- **dependency**: 免费档 API 权限变化已导致多个技能不可用（#707）。

**技术备注**: Python 脚本加 Claude Skill 描述文件，MIT，2025-10-19 建仓。数据源以 FMP 为主，组合复盘需要 Alpaca，另有 5 个技能只读公开 CSV、不需要 API key。

### [Likely7/Veyra-NRVideo](https://github.com/Likely7/Veyra-NRVideo) — NEW ⭐ 1,638（+256）| C++ | 信源：中

**它是什么**: 一个 Windows 上的视频播放和采集画面增强工具。你可以把本地视频、采集卡画面或 PS5 远程游玩画面接进来，它在 PC 显卡上实时做超分辨率（把低分辨率画面放大变清晰）、画质增强和补帧（在两帧之间插入生成帧，让画面看起来更流畅）。

**解决什么问题**: 主机玩家或看录像的用户想在 PC 显示器上看到更清晰、更顺滑的画面时，通常要在 OBS 插件、显卡厂商的视频增强功能和各种播放器之间拼凑。Veyra 把这几步放进一个程序，带实时预览。

**谁在用、怎么用**（来自 Issues/X/论坛）:
- 高端显卡用户调参: #32 报告在 RTX 4090 上 4K 超分加画质增强加 2 倍补帧时 GPU 占用接近 100%，降到 2K 超分后为 58%。
- 主机玩家接采集卡: NeoGAF 上有用户称 PS5 Pro 经 Elgato 采集卡接 RTX 5070 Ti 可以使用（个人说法，未验证）。
- 功能请求: #93 请求支持更多神经渲染方案。

**社区怎么评价**:
- 正面: X 上有一条把它和 OBS 插件对比后给出好评的帖子（转述）；二进制版本下载量累计数万次。
- 负面: #98 质疑 GPL-3.0 与 NVIDIA / AMD / Intel 闭源 SDK 链接的授权兼容性。
- 健康度: stars/subscribers 约 182:1；2026-09-09 建仓，作者账号 2025-11 注册。仓库有完整 C++ 工程（src、tests、shaders、CMake），每个版本附源码包。近期提交的作者信息未关联 GitHub 账号，部分提交只是更新群二维码和赞助链接。HN、Reddit 未找到讨论。

**风险与争议**:
- **宣传与可行性落差**: 简介写"PS5 GTA6 120FPS with DLSS 5"。DLSS 5 是 NVIDIA 2026 年发布的真实技术，但它需要游戏引擎提供运动矢量等数据，目前没有官方说明支持直接处理采集卡视频；PC 端补帧也不会改变主机渲染帧率，还会增加延迟。
- **compliance**: GPL-3.0 与闭源 GPU SDK 的链接授权存在疑问（#98）。
- **安全**: 发布包约 750 MB，本次没有核对二进制与源码的对应关系；GitHub 上已有至少三个同名复制仓库，下载时只认 Likely7 的 Release。
- **bus_factor**: 单一作者，提交者身份不透明，代码大量由 AI 辅助生成（仓库含 AGENTS.md 和执行手册）。

**技术备注**: C++ / Qt QML，CMake + vcpkg 构建，GPL-3.0。分 NVIDIA 和 AMD 两种便携包。
