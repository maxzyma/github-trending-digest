### [SmartlyDressedGames/U3-SDK](https://github.com/SmartlyDressedGames/U3-SDK) — NEW ⭐ 2,059（+524）| C# | 信源：中

**它是什么**: 免费开放世界僵尸生存沙盒游戏 Unturned 的官方源码仓库。开发商 Smartly Dressed Games 于 2026-07-07 把这款日活峰值超过 1 万的老牌游戏源码公开，供玩家和 modder 查看内部实现、提交修复和功能、制作深度 mod 与地图。

**解决什么问题**: 此前 Unturned 的 mod 生态只能基于反编译和外部脚本，看不到官方实现细节。源码开放后，modder 可以直接读官方逻辑、按官方结构提 PR、做更深度的定制，官方也能借社区力量修 bug——把一个封闭商业游戏的维护部分转成半开放协作。

**谁在用、怎么用**（来自 Issues/游戏媒体）:
- 服务器运维场景: issue #4760（57 评，最热）反映某次更新后服务器主功能失效，是服主和 modder 的核心痛点。
- 跨平台踩坑场景: #5331 Linux/Fedora 下 alt-tab 崩溃、#3844 合成物品数量显示错误、#5452 `%` 符号字体问题，均为真实游戏运行 bug。
- 加载方式: 需先装 Steam + Unturned 才能加载二进制；mod 不得暗示 SDG 官方背书（禁用"Unturned 2"等命名）。

**社区怎么评价**:
- 正面: Steam/GamingOnLinux 讨论普遍感激，有玩家为支持购买 Permanent Gold；作弊担忧已被官方回应（高质量反编译早已存在，BattlEye 反作弊代码仍私有）。
- 负面: HN/X/Reddit 直接独立讨论薄弱，多为游戏媒体转述。
- 健康度: 2,059 ⭐ / subscribers 47 ≈ 44:1（比值健康）；open issues 178（真实游戏 bug，非灌水）；贡献者仅 2 人（官方主创 SDGNelson + MoltonMontro），本质单人主导。

**风险与争议**:
- **bus_factor**: 仅 2 名官方贡献者、本质 Nelson 单人主导，社区 fork 尚未成形。
- **compliance**: 自定义 license（非标准开源，官方称未来"或"转 MIT），商用/衍生边界受限。
- **stability**: 更新后服务器功能失效（#4760）、多起跨平台崩溃 issue，源码刚开放处于磨合期。

**技术备注**: C#（Unity 引擎）；2017-10 创建的老仓，2026-07-07 首次公开源码；需 Steam + Unturned 二进制配合。

### [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) — NEW ⭐ 99,772（+1,391）| Markdown | 信源：中

**它是什么**: 一个把知名品牌设计系统（色板、字体、间距、组件状态等）抽取成 DESIGN.md 文件的合集。你把某个品牌的 DESIGN.md 丢进项目根目录，Claude Code / Cursor / Copilot / Gemini CLI 等编码 agent 就能据此生成"有该品牌质感"的 UI。

**解决什么问题**: 让 AI 生成 UI 时，不给设计约束就容易产出"通用米色 + Inter 字体 + 紫色渐变"的千篇一律界面。以往要靠贴截图或从零用文字描述设计语言。这个项目把设计规范固化成一个可直接投喂的 markdown 文件，主打原型提速和品牌一致性。

**谁在用、怎么用**（来自 Issues/评测）:
- 补充设计系统场景: issue #247（求补 shadcn/ui）、#131（cloudflare）、#376（antd）、#47（ChatGPT）等"求补某设计系统"请求，说明确有人想用。
- 文档失效痛点: #377 反映 README 外链到 getdesign.md 已失效，指向文档维护问题。
- 实战评测: Design Systems Collective、Stefano Salvucci 等独立评测偏正面，用于原型阶段快速套品牌风格。

**社区怎么评价**:
- 正面: 对抗"AI 通用风格"、原型提速，多篇独立评测认可；X 上有 KOL 安利（"Claude Code 做 UI 很烂，这个 repo 修好了"）。
- 负面: HN/Reddit 零独立讨论；issue 评论普遍 ≤4，讨论稀薄；仅捕获静态属性，微交互/hover 覆盖存疑。
- 健康度: 99,772 ⭐ / subscribers 391 ≈ 255:1（极高，典型 awesome 清单形态）；仓龄约 3 个月、3 天冲上万 star（爆发式）；贡献者仅 4 人，necatiozmen 独占 57 次提交，高度单人集中。

**风险与争议**:
- **vanity**: 255:1 高比值 + HN/Reddit 零讨论 + subscribers 仅 391，star 增长远超真实社区足迹；VoltAgent 组织长期靠 awesome-* 系列刷榜（trendshift 全球 #118），营销驱动明显。
- **bus_factor**: 单人维护、贡献者集中。
- **stability**: token 从公开站点一次性抽取，站点改版即过期；外链已失效（#377）。
- **compliance**: 非品牌官方授权、"inspired by"免责，商用需谨慎。

**技术备注**: Markdown 合集（无代码语言）；2026-03-31 创建；配合任意支持读取项目文件的编码 agent 使用。

### [vxcontrol/pentagi](https://github.com/vxcontrol/pentagi) — NEW ⭐ 19,437（+535）| Go | 信源：中

**它是什么**: 一个"全自动 AI 渗透测试"agent 系统。你用自然语言下发一个测试目标，它由一个 orchestrator 协调 researcher / developer / executor 三类子 agent，在 Docker 沙箱里跑 Kali Linux + nmap/metasploit/sqlmap 等 20 余款安全工具，自动完成侦察和漏洞利用。

**解决什么问题**: 传统渗透测试要人工编排一大堆工具、反复做侦察。pentagi 把这套流程交给 LLM 驱动的多 agent 自动执行，支持 12+ LLM provider、可 vLLM 自托管做 air-gapped 部署，定位是减少重复侦察和工具编排的"力量倍增器"，被 DevSecOps / bug bounty 场景当辅助。

**谁在用、怎么用**（来自 Issues/安全媒体）:
- 功能推进场景: issue #283（Telegram bot 集成）、#350（headless 爬虫 RFC）、#331（Google Vertex AI provider RFC）、#329（首次部署配置指南）多为 PR/RFC 类，但评论普遍 0-1，社区讨论深度与 star 量级不匹配。
- 独立评测: Help Net Security 等安全媒体有评测，佐证技术方向真实。

**社区怎么评价**:
- 正面: 多 provider、可自托管、Docker 沙箱隔离，工具编排能力被认可为"力量倍增器"。
- 负面: X 批评集中于"autonomous 更像营销定位"——长推理链易跑偏、有幻觉风险、遇 WAF/限流无法优雅恢复，共识是不能替代 pentester。
- 健康度: 19,437 ⭐ / subscribers 125 ≈ 155:1（偏高）；open issues 66；contributors 仅 8 人，核心提交集中在 sirozha/asdek 两人；2025-01 创建、持续维护（v2.1.0，MIT）。

**风险与争议**:
- **compliance**: 全自动攻击框架，仅适用于授权渗透测试/CTF/安全研究等合法场景，滥用与授权边界风险明确。
- **cost**: 多 agent 长链条推理，LLM API token 成本可能失控。
- **stability**: 多步序列幻觉、WAF/限流下不可靠，非生产级"零人工"。
- **bus_factor**: 双人核心维护。
- **vanity**: "AGI"命名 + 一条病毒推文放大，star 与 HN（2 分 0 评）/Reddit（缺席）/issue 深度 grounding 落差明显。

**技术备注**: Go；多 agent orchestrator + Docker 沙箱 + Kali 工具链；12+ LLM provider，支持 vLLM 自托管；创建于 2025-01，MIT 许可。
