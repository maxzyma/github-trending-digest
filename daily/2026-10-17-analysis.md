## 首次上榜项目

### [android/skills](https://github.com/android/skills) — NEW ⭐ 8,094（+36）| Kotlin | 信源：中

**它是什么**: Google Android 开发者关系团队维护的一套"技能说明书"。每个技能是一份 Agent 能读懂的任务指南，把 developer.android.com 上的最佳实践整理成步骤，Agent 遇到对应任务时按需加载。目前覆盖构建系统、相机、车载、端侧 AI、身份认证、Jetpack Compose、导航、性能、Google Play、安全、测试、TV、Wear、XR 等领域。

**解决什么问题**: 通用大模型对 Android 新版 API 和迁移路径掌握不稳，常写出过时代码。这个仓库只收录评测中模型表现差的场景，例如老项目从 XML 迁到 Compose、升级到 AGP 9、接入 Navigation 3、适配 edge-to-edge、用 r8-analyzer 排查混淆规则。开发者装上后，Agent 做这些任务时会照着官方步骤走，而不是凭训练数据猜。

**谁在用、怎么用**（来自 Issues/HN/X）:
- 多 Agent 安装：README 提供 `android skills add --all`（Android CLI）、Claude Code 的 `/plugin install android-skills --marketplace android/skills` 和 Codex 插件三种方式；#143（评论最多）请求直接支持 Antigravity 的 agy 安装，#47 反映 Antigravity 2.0 无法引用。
- 新技能需求：#64 请求 Android Lint 技能，#131 请求 AdMob 技能。
- Play 上架检查：#226 报告 Play Policy Insights 识别不了 version catalog 里的插件别名，说明已有人用它做上架前的政策检查。

**社区怎么评价**:
- 正面: 官方维护、内容来源明确；配套的 Android 官方博客《Android CLI and skills》（2026-04-16）在 HN 得到 315 分、138 条评论。Android 开发者 @github_skydoves 4 月的介绍帖约 13.4 万浏览，并做了配套的 MCP 服务。
- 负面: 问题集中在安装链路：`gh skill install` 只认精确路径（#48）、WSL 上 `android docs search` 崩溃（#200）、缺 Linux ARM 支持（#157）；#61 指出技能会自动安装 Android CLI，用户希望先征求同意。仓库本身在 HN 和 Reddit 无独立讨论，X 上以 KOL 转介为主。
- 健康度: subscribers 92，星数与 subscribers 比约 88:1；forks 537，open issue 36、open PR 1。2026-03-16 建仓，Apache-2.0。约 81 个提交，大多是机器人账号同步技能更新，约每一两周一次；插件版本 10-14 到 v1.0.15，GitHub Release 停在 4 月的 v0.0.3。

**风险与争议**:
- **dependency**: 主安装路径依赖 Android CLI，多个安装类 issue 尚未解决。
- **bus_factor**: README 写明不接受公开贡献，内容只能由官方单向更新，社区只能通过 issue 提需求。
- **stability**: 技能会自动安装 CLI（#61），在受管控的开发环境里需要先确认这一行为。

**技术备注**: 遵循 Agent Skills 开放格式（SKILL.md），按领域分目录；同仓提供 Claude Code 与 Codex 插件市场清单；官方文档位于 developer.android.com/tools/agents/android-skills。今日日增只有 36，属于官方仓的低幅上榜，10-12 和 10-14 各有一次技能更新，未见单一触发事件。

### [hmjz100/LinkSwift](https://github.com/hmjz100/LinkSwift) — NEW ⭐ 23,755（+538）| JavaScript | 信源：中

**它是什么**: 一个浏览器油猴脚本。在百度网盘、阿里云盘、中国移动云盘、天翼云盘、迅雷云盘、光鸭云盘、夸克网盘、UC 网盘、123 云盘的网页里勾选文件，它会取出文件的真实下载地址，交给浏览器、IDM、Aria2/Motrix、cURL、比特彗星等下载工具。它改自"网盘直链下载助手"（syhyz1990/baiduyun）。

**解决什么问题**: 多数国内网盘在网页端限制下载，要求安装官方客户端。在 Linux、NAS 或远程下载场景里装客户端不方便，也没法用 IDM、aria2 这类多线程工具。LinkSwift 让用户在网页里直接拿到自己文件的下载地址。README 明确声明不破解限速，速度仍取决于账号权益和网盘策略。

**谁在用、怎么用**（来自 Issues/中文社区）:
- 配合 aria2 远程下载：linux.do 上有用户用 RPC 接 aria2，在千兆宽带上测到约 50 MB/s。
- 不装客户端下载自己网盘的文件：小黑盒的使用教程 10-14 被 MSN 转载，CSDN、知乎、什么值得买、异次元软件站也有教程；脚本猫页面显示累计安装约 62 万次。
- 网盘改版后失效是最常见的反馈：迅雷 #482（9 条评论）、#490、#495，百度 #489、#477，夸克 #492、#497，123 云盘 #491；社区贡献者提交了修复 PR #500。

**社区怎么评价**:
- 正面: 覆盖网盘多，可对接主流下载工具；v1.0.9.7 起去掉了原脚本的云服务，不经第三方解析服务器。
- 负面: 失效频繁，近一个月有十多个失效 issue；#507 反映用比特彗星和 IDM 下载仍然限速。不少教程用"满速""告别限速"做标题，和 README 的声明相反，用户预期容易被拉高。HN、Reddit、V2EX 无讨论，X 未检索到，传播几乎全在中文教程站和 linux.do。
- 健康度: subscribers 75，星数与 subscribers 比约 317:1；forks 1,439，open issue 32、open PR 6。2022-08-10 建仓，AGPL-3.0，最近一次推送是 9-10。README 自述"只有一个人在修改"，最近的提交绝大多数来自作者本人。正式版 v1.1.3、测试版 v1.1.4 只写在 README 更新日志里，GitHub Release 停在 2022 年。

**风险与争议**:
- **compliance**: 下载请求会伪装官方客户端的 UA，用来绕开"必须用客户端下载"的限制，可能违反网盘服务条款；项目自称技术中立。
- **privacy**: 脚本运行在已登录的网盘页面，能接触登录凭据，并声明可以向任意域名发请求；安全性完全取决于作者和下载渠道，README 提醒 Greasy Fork 上有冒名的修改版。
- **dependency**: 每家网盘一改网页就可能失效，修复速度取决于单个维护者。
- **bus_factor**: 单人维护。

**技术备注**: 油猴用户脚本，需先装 Tampermonkey，可从 GitHub、Gitee、脚本猫、OpenUserJS 安装。百度网盘走 OAuth 获取访问令牌，v1.1.1.6 起不再读取 BDUSS Cookie。今天的增长与代码更新无关，对应 10-14 起的中文教程二次传播（推断：由星数时间线与转载日期对照得出）。
