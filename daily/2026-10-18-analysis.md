# GitHub Trending 深度分析 — 2026 年 10 月 18 日（周日）

_Claude Code、OpenCode、Orca 三个编程 Agent 客户端同日回榜，13 项里 12 项围绕编程 Agent；今日没有新面孔，求职框架 ai-job-search 升到第二并跨过 5 万星。_

_项目总数: 13 | 首次上榜: 0 | 重新上榜: 4 | 已上榜更新: 9 | 数据源: https://github.com/trending_

## 本日主线

**主线一：榜单地图 — 13 项分五组，客户端、插件技能、记忆检索三层同时在榜。** 今日分组如下：

- **编程 Agent 客户端与工作台**（3 项，均为 RE）—— `stablyai/orca`（RE，#8，95,470 ⭐）同时管理多个编程 Agent 的桌面与手机工作台，`anthropics/claude-code`（RE，#9，151,788 ⭐）Anthropic 的终端编程 Agent，`anomalyco/opencode`（RE，#11，215,409 ⭐）开源编程 Agent
- **插件目录与通用技能框架**（5 项）—— `anthropics/claude-plugins-official`（=，榜首，+1,397）Claude Code 官方插件目录，`affaan-m/ECC`（=，#3）Agent 配置与技能合集，`HKUDS/CLI-Anything`（=，#4）把现有软件包装成命令行给 Agent 调用，`android/skills`（=，#7）Google 维护的 Android 开发技能库，`ruvnet/ruflo`（↓6，#12）多 Agent 编排
- **Agent 记忆与检索**（2 项）—— `akitaonrails/ai-memory`（RE，#6）让不同厂商的编程 Agent 共享长期记忆和交接记录，`xerj-org/xerj`（=，#13）给 Agent 用的本地检索引擎
- **职业流程技能包**（2 项）—— `MadsLorentzen/ai-job-search`（↑9，#2，+1,365）基于 Claude Code 的求职流程，`K-Dense-AI/scientific-agent-skills`（↓3，#5）科研技能包
- **个人本地工具**（1 项）—— `debpalash/VoiceStudio`（=，#10，+2,125 日增第一）本地配音与声音克隆

和 10-17 相比，13 项中留下 9 项。`mksglu/context-mode`、`obra/superpowers`、`cursor/plugins` 和网盘脚本 `hmjz100/LinkSwift` 离榜，补进来的 4 项全是回归老面孔，没有首次上榜项目。昨天的榜单集中在插件和技能目录，今天把这些扩展能力的"宿主"也带了回来：客户端本身、跨客户端的记忆层和插件目录同时在榜，编程 Agent 相关项目从 11 席增加到 12 席。

**主线二：三个客户端同日回榜 — 都在密集发版，方向各不相同。** Claude Code 10-14 至 10-16 连发 v2.1.300、v2.1.301、v2.1.302，新增内容集中在 mods 扩展接口、OpenTelemetry 事件字段和自动模式分类器的模型选择；v2.1.302 还提示独立的 Claude Design（claude.ai/design）将于 2026-12-14 关闭。OpenCode 这一周在做版本线拆分：v1.19.2 起 1.x 用户不会再被自动升级到 OpenCode 2，升级 2.x 需要显式选择，Homebrew Core 已改为跟踪 2.x；v1.19.1 停掉了会话分享功能，已有分享链接失效。Orca 的变化最大，8-13 上次在榜时是 44,364 星，现在 95,470 星，两个月翻了一倍多；它几乎每天发版，10-16 和 10-17 的版本重点是"原生聊天"界面（逐轮查看编辑、按会话设置权限）和共享技能安装，后者新增支持 20 个 Agent。

**主线三：记忆层开始跨客户端 — ai-memory 3.x 把"换工具不丢上下文"做成插件。** ai-memory 9-22 之后首次回榜，期间从 7,718 星涨到 9,942 星，并在 10-13 至 10-17 连发 3.0.0、3.0.1、3.1.0、3.1.1 四个版本。3.0 把仓库变成 Claude Code 和 Codex 都能直接安装的插件市场；3.1 新增 IBM Bob 支持，并在用 `ai-memory run` 从一个 Agent 切到另一个时，把上一个会话的本地历史临时交给接手的 Agent，远端服务器不接收本地路径和对话正文。和主线二合起来看，用户同时使用多个编程 Agent 已经很常见，Orca 管理多个 Agent，ai-memory 管理它们之间的交接，xerj 则提供共用的本地检索。

**主线四：榜单解读提醒 — 排名、日增和维护负载要分开看。** 今天排名和当日星数依旧对不上：VoiceStudio 日增 2,125 排 #10，xerj 日增 1,160 排末位，Claude Code 只增 179 却排 #9。Orca 的星数与 subscribers 比约 641:1，open issue 4,322、open PR 4,222，对一个 6 月才进入本 tracker 的项目来说，维护负载需要持续观察。xerj 的星数与 subscribers 比约 356:1，仍以作者账号传播为主。ruflo 在 10-18 凌晨给 README 加了自动递增的动画下载计数，提交说明称其为示意动画，并另加了一行"已核验"总数；读这类徽章时不要把动画数字当作实测下载量。
