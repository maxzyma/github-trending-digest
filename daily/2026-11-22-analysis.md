**主线二：周日日增普遍回落，只有 Claude-BugHunter 和 stitch-skills 上升。** 16 项的「今日」星数合计从 11-21 的 11,839 降到 10,273，14 项下降。Claude-BugHunter 从 +1,622 升到 +1,803，是全榜唯一日增过 1,800 的项目，领先第二名 firecrawl（+1,006）近 800。stitch-skills 从 +315 小涨到 +326。昨天涨幅最大的后半榜回吐明显：Ghost Downloader 从 +1,082 到 +779，autoclip 从 +979 到 +683，minimind 从 +847 到 +488。

**主线三：12 个仓库有实质更新，三个项目发了新版本，MCP 接入出现在四个项目的改动里。**

- **last30days** 两天发了两版。11-21 的 v4.5.0 新增 OpenCode 的浏览 MCP 通道，用来取 X 和 Reddit 数据（#1537），并停止把 `APIFY_API_TOKEN` 发给 ScrapeCreators（#1549）；11-22 的 v4.6.0 在没有 API key 时，用网页检索加 yt-dlp 抓 TikTok 和 Instagram 短视频（#1533）。
- **AutoClip** 在 11-22 发布 v1.5.9，合入 1.5.9 RC 分支（#659）。这一版把封面、文案和各平台投稿入口整合到一个成片发布页（#648），桌面包覆盖 Apple Silicon Mac 和 Windows x64，另附 CLI / MCP 包，可以用 `uvx autoclip-mcp` 启动。
- **app-store-compliance** 在 11-22 连发 2.5.0 和 2.5.1，新增三条截止日期：Apple 中国大陆 App 合规声明（2027-01-31）、Google Play 交易者身份声明（2027-02-01）和交易者信息展示（2027-03-01），跟踪的截止日期增至 112 条，覆盖 33 个司法辖区和平台范围。
- **opensre** 把已配置的 MCP 服务桥接成带类型和权限闸门的 agent 工具（#7085），新增 `opensre integrations setup mcp` 配置命令（#7088）；/auto high 以下级别的外部写操作改为先询问用户（#7083）。
- **Firecrawl** 新增 `x-firecrawl-work-contact-only` 请求头，返回结果里不带个人联系方式字段（#5948），并为 MCP 操作日志增加可选的资源前缀（#5950）。
- 其余有提交的仓库：minimind 13 次提交（学习率 warmup、agent 训练的工具调用报错），OpenVINO 把默认 C++ 标准设为 C++20（#39146），Ghost Downloader 修了一批 m3u8 下载问题，AFFiNE 改进同步稳定性（#15883），diagram-design、cursor/plugins 和 Claude-BugHunter 各有小修。superpowers、CLI-Anything、nginx、stitch-skills 两天内没有新提交。

**主线四：榜单解读提醒 — 昨天提醒的两个今年建仓项目，今天都有了实质更新。** opensre 从 11-21 起恢复功能提交，见主线三。app-store-compliance 发了两个版本，subscribers 从 6 个变成 9 个，和 4,026 星相比仍然偏少，独立用户的使用反馈还要继续看。另外，本文总星数取自 11-23 运行时的 GitHub API，比 Trending 页面采样晚，所以「较 11-21 增加」普遍大于当天的「今日」星数。
