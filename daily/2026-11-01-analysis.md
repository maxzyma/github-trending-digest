### [Orkas-AI/Orkas](https://github.com/Orkas-AI/Orkas) — NEW ⭐ 6,335（+1,044）| JavaScript | 信源：弱

**它是什么**: 一个装在 Mac 或 Windows 上的"AI 团队"应用。你告诉它要做的事，一个总指挥 Agent 把目标拆成待办，交给内置的 16 个专业 Agent（写文案、做 PPT、剪视频、写代码等），也可以调用你电脑上已装的 Claude Code、Codex、OpenCode 等编程助手来干活。

**解决什么问题**: 以前要在多个 AI 工具之间手动切换、复制粘贴上下文，再自己盯进度；Orkas 想把分工、排期和定时任务放进同一个桌面应用，对话、文件和知识库默认存在本机。

**谁在用、怎么用**（来自 Issues，未找到外部独立讨论）:
- 场景 1: 在多个资料库之间移动文件时编辑内容丢失（#131），说明有人在用它管理多个项目的文件。
- 场景 2: Windows 上同时跑多个任务时卡顿（#137）；希望自动化只在工作日运行、Agent 可换头像（#136）；希望内置浏览器补齐日常功能（#145）。
- 以上 4 个 issue 的提交账号均注册于 10-29 到 10-31，各只有 1 到 2 个公开仓库、0 个关注者，无法确认是独立用户。较早的 #67 要求按平台提供预编译原生模块，来自 2025 年注册的账号。

**社区怎么评价**:
- 正面: 工程在持续推进，约每 10 天发一版（v2026.10.1、10.17、10.27），10 月底核心成员合入了 OAuth、跨资料库移动等修复。
- 负面: HN 按 "Orkas" 搜索无结果；X 上搜到的多是同名不同项目；Reddit 未找到帖子。能找到的外部曝光主要是工具目录站和核心贡献者在其他 awesome 列表里提交的推荐。
- 健康度: 151 个关注者，星数与关注者之比约 42:1；open issue 加 PR 共 7 个；仓库创建于 2026-04-29；最近三版 GitHub 安装包下载量为 472、161、177。

**风险与争议**:
- **vanity**: 6 千多星对应 5 个 issue，近期 issue 多来自新注册账号，外部讨论几乎为零，热度需要谨慎解读。
- **cost**: 安装包版内置 Orkas 托管模型，送 500 积分，之后需买积分或订阅（$11.99/月起）；自带 API Key 则按模型服务商计费。
- **dependency**: 共享项目、云同步、把应用发布成网页只在需要登录的安装包版里有，开源源码版没有账号层，也不支持这些功能。
- **privacy**: 语音输入会把音频发到 Orkas 识别；可选的云同步把所选数据存到 Orkas 服务器。使用自带 Key 时，模型请求从本机直连服务商。

**技术备注**: JavaScript，MIT 许可。安装包支持 macOS 12+ 与 Windows 10+；Linux x64/arm64 目前只能从源码运行，源码版可连本地模型离线使用。自定义模型支持 OpenAI 兼容和 Anthropic 兼容接口。

### [vorssaint/vorssaint-utils](https://github.com/vorssaint/vorssaint-utils) — NEW ⭐ 31,928（+501）| Swift | 信源：中

**它是什么**: 一个常驻 Mac 菜单栏的免费工具箱。一个应用里包括按应用分别调音量、系统监控、窗口切换与吸附、Dock 预览、剪贴板历史、文本片段、卸载器、Homebrew 图形管理、端口管理、录屏等功能。

**解决什么问题**: Mac 用户常为这些小功能分别购买或安装多个付费工具；vorssaint-utils 把它们合到一个开源应用里，各功能可单独开关。

**谁在用、怎么用**（来自 Issues/X）:
- 场景 1: 用它替代系统窗口切换器，改版后有用户要求恢复旧版切换器（#710，18 条评论）；也有人报告切换器不切换（#961）。
- 场景 2: 用卸载器和应用更新功能管理软件，反馈卸载器拖入应用无反应（#1582）、更新检查误报（#1465）。
- 场景 3: X 上多位独立用户自发推荐，最常提到的是按应用调音量。
- 社区在补功能：平滑滚动（PR #1040，47 条评论）、阿拉伯语从右到左排版（#1149）、端口管理器（#1260）。

**社区怎么评价**:
- 正面: 发版密集，v3.4.2（10-21）和 v3.4.3（10-29）的 DMG 下载量分别为 144,914 和 68,551；构建经 Apple 开发者签名与公证，可用 `brew install --cask vorssaint` 安装。
- 负面: 功能面很宽，切换器、更新、卸载等核心功能都出过回归；HN 上 8 月有 2 条帖子，均无评论。
- 健康度: 44 个关注者，星数与关注者之比约 726:1；open issue 加 PR 1,342 个，历史 issue 约 1,800 个；作者 1,283 次提交，第二名 146 次。

**风险与争议**:
- **bus_factor**: 作者一人贡献绝大部分提交，上千个待处理 issue 和 PR 主要靠他消化。
- **stability**: 十几种功能同在一个应用里，单个模块的回归会影响整体体验，升级前可先看 issue 区。
- **privacy**: 部分功能需要辅助功能、录屏等系统权限，README 称均为可选；录屏可生成限时分享链接，这一功能会上传文件。README 声明无账号、无统计和追踪，联网仅限更新检查、测速、Homebrew 操作等可见动作。

**技术备注**: Swift，GPL-3.0。仅支持 Apple Silicon、macOS 14 及以上。
