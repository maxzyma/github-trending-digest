昨天的 nightly-labs/openbot、elayadesign/ai-design-skills 和 Claude-Code-Game-Studios 落榜。今日单日涨星最多的是 impeccable（+2,300）、DeepTutor（+2,282）和 jailbreaks（+2,055），排名靠前的却是 claude-mem 和两个 Agent 工作区，排名和单日星数并不一一对应。

**主线二：技能包有个人、社区和厂商三种来源，头部两家星数接近。** mattpocock/skills 是一位 TypeScript 讲师公开的个人技能目录，距上次在榜（10-11）多了约 2.3 万星，达到 307,513；obra/superpowers 是社区维护的技能框架，309,464 星，两者只差约 2,000。厂商侧，anthropics/skills 是 Anthropic 官方技能库，10-28 把 mcp-builder 技能改为教 MCP TypeScript SDK 第 2 版；expo/skills 是 Expo 团队给 React Native 项目写的 24 个技能。impeccable 则专攻界面设计，连续在榜 7 天。对开发者来说，选技能包时可以先分清它是个人工作流、通用框架，还是某个框架或服务的官方用法；后两类更新跟着产品版本走。

**主线三：编程助手外围工具密集发版 — claude-mem 修复了在用户账号上隐藏调用 Codex 的问题。** claude-mem 10-30 发布 v15.7.0：它的"My Work"自动刷新在 Claude Code 的回答被拒收后，会换用本机下一个已登录的 Agent，装了 Codex 的机器因此在用户的 ChatGPT 账号上跑了隐藏任务（#5189 报告四天约 230 次）；新版改为留在原 Agent 上重试。t3code 是 ping.gg 团队做的编程 Agent 客户端，距上次在榜（10-06）多了 7,146 星，几乎每天出 nightly 版。JetBrains 的 thinkrail 10-30 加入自定义 OpenAI 兼容模型服务器和 pi 扩展包管理。Agent 工作区一侧，OpenMausBot v0.1.134 让 Mac 上做完的电脑任务可以保存步骤，下次不调用模型直接重放。

**主线四：榜单解读提醒 — 排盘引擎和越狱提示集的涨星需要结合社区足迹看。** ziwei-doushu 从 10-26 的 7,661 星涨到 11,250 星，关注者 47 个、open issue 3 个，作者当天把配套的商业排盘站更名为 OURANIC。jailbreaks 两天从 9,115 涨到 11,119 星，10-28 之后没有新提交，使用这些越狱提示本身违反主流模型厂商的使用条款。
