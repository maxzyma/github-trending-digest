- **成熟开发与机器学习框架**（4 项）—— `flutter/flutter`（RE，#7）、`tensorflow/tensorflow`（NEW，#8，知名老项目首入 tracker）、`pytorch/pytorch`（RE，#10）、`huggingface/transformers`（RE，#11）

和 10-10 相比，昨天的 11 项留下 6 项，`open-code-review`、`litellm`、`agent-skills`、`lingbot-map`、`SwiftUI-Agent-Skill` 退场。新进 7 项里只有 TensorFlow 是首次出现，其余 6 项都是回榜老面孔。

**主线二：前三名都是本地运行的重型工具 — rea 和 ArtCraft 各有实质更新。** `rea`（#1）今天上午发布 6.4.0，新增通过 ADB 检查安卓设备、拉取分包 APK、读取日志和截屏，能对接用户自己启动的 JEB 反编译服务，Ghidra 一侧加入 Windows PE DLL 和 MIPS ELF 分析，并给 Kimi 这类对工具描述长度有上限的 MCP 客户端提供精简模式。从 10-08 的 6.0.0 算起，四天内发了五个版本。`artcraft`（#3）10-10 把许可证改为 MIT 或 Apache-2.0 二选一（#2043），同一天新增 `artcraft-native`：一个纯 Rust（egui）写的桌面端，先做出图、出视频和配音（#2067、#2079）。`AnyPS5`（#2）10-10 以来又合入上百个社区 PR，多数在补 libc 函数，正式版本仍停在 9-28 的 v0.1.1。

**主线三：四个成熟框架同日回榜 — 各自都有近期版本可看。** TensorFlow 2.22.0-rc0（9-24）不再默认依赖 TensorBoard，用到 `tf.summary` 或 TensorBoard 回调的项目升级时要单独安装；PyTorch 9-30 发布 2.14.1 补丁版；Transformers 10-06 发布 v5.19.0，新增 Google 的多模态嵌入模型 EmbeddingGemma 2，并要求所有能算路由 logits 的 MoE 模型统一返回它，属于破坏性变更。Flutter 的 GitHub releases 页面不随版本更新，今天无法从仓库确认对应的版本事件。四个项目当日增星都在 100 以内（TensorFlow 只有 +26），能进榜更多说明周日整体增量偏低，而不是这几个框架突然升温（推断，依据是排名与当日星数）。

**主线四：榜单解读提醒 — 回榜的两个 skill 项目长期没有代码更新。** `andrej-karpathy-skills` 最后一次推送是 4-20，距今 174 天，星数仍从 9-09 的 211,484 涨到 218,410；`context-mode` 自 6-29 发布 1.0.169 后只有自动更新安装统计的 CI 提交，仍有 342 个 open issue 和 PR。两者更接近"被持续收藏的静态资料"，不宜按"活跃维护的工具"理解。`rea` 的星数与 subscribers 比约 316:1，按 API 一天涨了近 3 万星，提交和发版是真实高频，但实际用户规模还要看后续外部 issue。
