**主线二：名次没动，日增变了，后半榜的涨幅放大得最明显。** 16 项的「今日」星数合计从昨天的 8,632 升到 11,839，11 项上升，5 项下降。升幅最大的集中在榜单后半段：autoclip 从 +126 到 +979，opensre 从 +38 到 +466，Ghost Downloader 从 +341 到 +1,082，AFFiNE 从 +182 到 +676，minimind 从 +238 到 +847，nginx 从 +73 到 +246。下降的是前半榜的几个技能项目：superpowers 从 +2,028 到 +890，last30days 从 +954 到 +681。结果是 #15 的 Ghost Downloader（+1,082）日增高于 #2 的 superpowers（+890），可见 Trending 的名次不等于当日星数的排序。日增放大的 6 项里，Ghost Downloader 在 11-20 发了新版本，AFFiNE 有 3 次小提交，其余 4 项的默认分支在过去一天没有新提交。

**主线三：7 个仓库在过去一天有实质更新，技能包里 last30days 和 Claude-BugHunter 动作最大。**

- **last30days** 在 11-20 发布 v4.4.0，新增面向在职人士的人物调研，可以用 `--employer`、`--linkedin`、`--email` 参数限定对象（#1538）；同一版还收了几项修复，包括 GitHub 调研证据只取公开仓库（#1517）和 MCP 调用时遵守 `save=false`（#1515）。
- **Claude-BugHunter** 给自带的 MCP 服务加了 `get_report` 工具，不需要密钥就能读取已公开披露的漏洞报告正文（#187）。同一天合入三项修复：报告草稿不再带出本机的系统登录名（#193），PowerShell 5.1 下脚本解析崩溃（#192），Windows 默认编码下写日志和报告崩溃（#191）。
- **cursor/plugins** 新增 Sabre Developer Hub 插件，连接 Sabre 托管的文档 MCP 服务（#1307）；Front 插件不再要求用户填写 client ID 和 secret（#1295）。
- **stitch-skills** 合入同一位贡献者的三个校验修复：识别 className 表达式里的硬编码颜色（#103）、拒绝 React Native 组件里的 Web 标签（#104）、识别 Tailwind v4 的 CSS 优先配置（#105）。
- **Firecrawl** 给托管 MCP 的 API key 请求加了独立的代理密钥（#5935），把威胁防护的组织域名列表上限提到 10,000 条并加索引（#5891）。
- **Ghost Downloader** 发布 v4.5.11，新增德语、法语、印尼语、意大利语和韩语。
- **OpenVINO** 的默认分支在过去一天有 28 次提交，集中在 GPU 插件和各模型前端。

**主线四：榜单解读提醒 — 昨天提到的两个今年建仓的项目，今天日增翻倍以上，仓库本身没有新提交。** app-store-compliance 从 1,879 星涨到 2,782 星，subscribers 从 5 个变成 6 个，最新版本仍是 11-15 的 v2.4.0。opensre 日增从 +38 升到 +466，主分支在 11-18 之后没有新提交，11-21 发布的按日期编号版本变更列表为空。两个项目对应的需求是真实的，独立用户的使用反馈还需要继续观察。另外，「今日」星数取自 Trending 页面，总星数取自 GitHub API，两者采样时间不同，相减对不上属正常。
