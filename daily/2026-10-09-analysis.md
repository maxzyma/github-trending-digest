## 首次上榜项目

### [storytold/artcraft](https://github.com/storytold/artcraft) — NEW ⭐ 8,116（+2,103）| Rust | 信源：中

**它是什么**: 一个给画师、设计师和影视创作者用的 AI 出图、出视频桌面工作台，有 Windows 和 macOS 版，也能在浏览器里用。和只写提示词不同，用户先在 2D 画布和 3D 场景里摆好道具、角色姿势和机位，再交给模型生成。

**解决什么问题**: 只靠文字提示词生成图片和视频，很难控制构图、角色一致性和镜头位置，同一场景换个角度往往就对不上。ArtCraft 把"先摆场景、再生成"做成一个工具，并接入约 62 个第三方模型（Nano Banana、GPT Image、Seedance、Kling、Veo、Sora、Hunyuan 3D 等），让用户在一个界面里切换。软件本身免费，生成要调用付费模型服务。

**谁在用、怎么用**（来自 Issues/HN）:
- 视频生成：有用户反映 Seedance 2.0 生成长期卡在 95%，并指出更早的同类问题没修（#1439）。
- 自带 API key：FAL 下线了 OpenAI 的 BYOK 接口，导致相应功能失效（#1172）。
- 本地生成与平台：有人希望接入本地的 ComfyUI（#968），说明目前只能走云端；另有 Linux 支持请求（#2002），社区已自行做了 Arch 打包和 NixOS 模块。

**社区怎么评价**:
- 正面: 1,156 个 fork 不算少，有社区成员主动打包；少数 HN 评论认为基础功能能跑。
- 负面: 10-04 的 HN 帖"ArtCraft Apps – open-source Adobe compatible suite written in Rust"拿到 142 分、约 209 条评论，主要批评是功能大量不可用、卡顿、快捷键无效，并质疑"Adobe 兼容"的说法；10-08 Tedium 的评论文章在 HN 上约 27 分。PetaPixel 转述作者说法：用 Opus 5.5 写出 7 个 Adobe 产品的替代品，目前是 alpha。
- 健康度: 8,116 ⭐ / 50 subscribers（约 162:1）/ 64 open issues。仓库建于 2022-03（前身是 Storyteller.ai 的代码），10-07 仍有推送。贡献者 API 显示作者一人主导。Reddit 上未找到原帖，X 上只有官方账号 @get_artcraft 的宣传，未见独立开发者讨论。

**风险与争议**:
- **dependency**: 生成全部依赖外部模型 API，FAL 接口变化已造成功能失效（#1172）。
- **cost**: 软件免费，但模型调用费用和是否需要账号、积分，官网没有写清楚。
- **stability**: 生成卡住（#1439）、模型参考图失效（#963）；新的 Apps 套件仍是 alpha。
- **compliance**: GitHub 识别不出标准许可证，主仓许可文件自称是尚在起草的 fair source 文本，与作者在 HN 上的 MIT/Apache 说法不一致；"Adobe compatible"的宣传也有商标风险。
- **bus_factor**: 维护集中在作者一人。
- **vanity**: 本轮热度主要来自"AI 重写 Adobe"话题，HN 评价以负面为主，热度大于对本仓功能的验证。

**技术备注**: Rust 与 TypeScript 为主，少量 Python 和 Shell；桌面端支持 Windows/macOS，Linux 需自行从源码构建；生成走云端第三方模型。
