## 首次上榜项目

### [EpicGames/raddebugger](https://github.com/EpicGames/raddebugger) — NEW ⭐ 7,875（+90）| C | 信源：中

**它是什么**: 一个给 C/C++ 程序员用的图形调试器，作用和 Visual Studio 自带的调试器类似：让程序停在某一行，查看变量、内存、线程和调用栈。它原本由 RAD Game Tools 开发，现归 Epic Games 维护，主要作者是 Ryan Fleury。

**解决什么问题**: 在 Windows 上调试大型 C/C++ 项目（尤其是游戏和引擎）时，开发者通常只能用 Visual Studio，启动慢、大工程下界面卡顿。RAD Debugger 以速度和可视化为卖点，可同时调试多个进程，并配套自研的 RADDBG 调试信息格式和 PDB 转换器。9-30 发布的 v0.9.29-alpha 首次支持 Linux x64 原生调试（读 DWARF 调试信息），并新增 `raddbg_server` 远程调试，进程间通信改为走 socket（默认端口 7423）。10-01 Arch Linux 的 AUR 仓库上架了社区打包版本。

**谁在用、怎么用**（来自 Issues/X）:
- Linux 首批试用：9-30 以来新开约 31 个 issue，多数来自 Linux 用户：调试 Factorio 时卡死并持续占用内存（#996）、除零崩溃（#993）、GCC Release 构建下点"Add Target"崩溃（#985）、调用 `dlsym` 时报异常（#979）、144Hz 屏幕帧率偏低（#976）、`build.sh` 语法错误（#997）。
- 非主流工具链：有人用它调试 Odin 语言程序（#998）和 MinGW 生成的 DWARF（#994）；也有人报告调试器会改变被调试程序的行为（#989）。
- 长期遗留：读不到 `/DEBUG:fastlink` 生成的 PDB（#763），Unicode 支持问题（#6）从 2024 年开到现在。

**社区怎么评价**:
- 正面: 游戏和引擎开发者把它当作 Visual Studio 调试器的替代品；作者每发一个版本都在 X 上同步，Linux 版本发布后 daily.dev 有报道，有开发者在 5 月看到 Linux 运行片段时称其"非常接近完成"。
- 负面: Linux 版在 README 中自称"非常早期"，不支持 fork/vfork，位域类型信息仍不正确；Linux 尚无官方二进制，要自己从源码构建。
- 健康度: 7,875 ⭐ / 62 subscribers（约 127:1）/ 384 forks / 311 open issues。2024-01 发布，10-07 当天仍有 8 次提交。HN 上的主要讨论是 2024-01 首发帖（148 分、52 条评论），这次 Linux 版本未见 HN 热帖；Reddit 未搜到讨论。

**风险与争议**:
- **stability**: 仍是 alpha，Linux 版本处于早期阶段，首批 issue 以崩溃和卡死为主。
- **bus_factor**: 提交高度集中，Ryan Fleury 约 3,309 次、第二位贡献者约 1,284 次，第三位只有约 30 次。
- **dependency**: 只支持 x64；Linux 需自行构建，macOS 只有社区移植尝试。

**技术备注**: C 语言，MIT 许可；Windows 版读取 PDB，Linux 版读取 DWARF；自带 RADDBG 调试信息格式与转换器。今日 +90 星在榜单中最少，上榜更可能来自 Linux 版本发布后的持续关注，未找到 10-08 当天的单独触发事件。
