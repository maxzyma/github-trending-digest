## 本日主线

**主线一：榜单地图 — 17 项里 13 项是创建多年的基础项目，Agent 赛道只剩 4 项。** 11 个 NEW 全是首次进入本 tracker 的知名老项目，另有 Rust、Angular 回榜。今日可分 4 组：

- **编辑器与开发工具**（4 项）：`zed-industries/zed`（NEW 榜首，93,664 ⭐）、`microsoft/vscode`（NEW，#11）、`nushell/nushell`（NEW，#12）、`astral-sh/ruff`（NEW，#17）
- **编程语言与 Web 框架**（5 项）：`rails/rails`（NEW，#3）、`rust-lang/rust`（RE，#5）、`react/react`（NEW，#6，252,264 ⭐ 全榜最多）、`angular/angular`（RE，#7）、`symfony/symfony`（NEW，#8）
- **基础设施与底层库**（4 项）：`mpv-player/mpv`（NEW，#4）、`prometheus/prometheus`（NEW，#9）、`etcd-io/etcd`（NEW，#13）、`openssl/openssl`（NEW，#14）
- **Agent 技能与数据层**（4 项）：`NVIDIA/auto-ontology`（↓1，#2）、`google/skills`（↓2，#10）、`mattpocock/skills`（↓13，#15）、`cloudflare/security-audit-skill`（RE，#16）

昨天的 14 项今天只留下 3 项，gstack、agent-desktop、agent-browser、worktrunk、Scrapling 等全部退场。13 个老项目今天合计只涨 2,091 星，4 个 Agent 项目合计涨 7,167 星，占全榜约 77%。

**主线二：同一周的发版潮 — 11 个 NEW 里 7 个在 11-04 至 11-05 发了版。** Zed 1.27.0、Rails 8.1.4.1 / 8.0.5.2、Symfony 8.2.0-BETA1 与 8.1.11、VS Code 1.145.0 在 11-04 发布，mpv 0.42.0、Prometheus 3.16.0、Ruff 0.17.4 在 11-05 发布，回榜的 Angular 也在 11-06 发了 22.2.5。对使用者影响最大的有三件：

- **Rails 8.1.4.1 是安全版本**：发布说明列出 21 个 GHSA 安全公告编号，涉及 Active Support、Active Record、Action View、Action Pack 等多个组件，8.0 线同步发 8.0.5.2。其中 `ActiveSupport::MessagePack` 的修复改变了序列化格式，旧版 Rails 读不了新版写出的数据，多版本混跑的集群要注意升级顺序。
- **mpv 0.42.0 是一年来的首个正式版**（上一个是 2025-12-21 的 0.41.0）：网络层换成基于 libcurl 的实现，支持 HTTP/2、HTTP/3；可以直接播放 DVD、蓝光的 .iso 镜像并操作光盘菜单；新增右键菜单和 `floating` 控制栏布局。
- **Prometheus 3.16.0** 加入实验性的查询成本估算和执行上限（`--enable-feature=query-cost`），以及实验性 `integral()` 函数；平滑和锚定向量选择器转为稳定。

没有本周新版本的老项目是 React（10-14）、Rust（10-16）、etcd（10-22）、OpenSSL（10-23）、Nushell（10-04），发版只能解释一部分上榜，这几个找不到明确的单一触发事件。

**主线三：两款编辑器都在往"Agent 宿主"方向走。** 榜首 Zed 和 #11 VS Code 本周的新版重点都在 Agent。VS Code 1.145 的 Agents 窗口能预览远程 Agent 会话里的应用；同一会话下的子会话可以混用不同的 Agent 运行框架，例如 Claude 和 Copilot（预览功能）；本地自动化任务支持五段式 cron 定时。Zed 1.27 降低 Agent 面板的内存和 CPU 占用，按仓库最近 3 条提交的风格生成提交信息，同时移除了在大仓库里容易卡住的 Agent "检查点"功能，最低系统要求升到 macOS 12。在两款编辑器之间选择的读者，可以重点比较 Agent 会话管理和多 Agent 编排。

**主线四：榜单解读提醒 — 排名不按当日 star 排，老项目的上榜不等于"突然变火"。** Zed 日增 +306 排第 1，cloudflare/security-audit-skill 日增 +2,548 却排 #16，OpenSSL 只涨 26 星也在榜。老项目的单日增量相对体量很小，上榜更多反映发版带来的访问，看不出用户量变化。另一个方向的样本是 cloudflare/security-audit-skill：最后一次提交在 9-14，10-26 离榜后 12 天又涨了约 1.7 万星，今天回榜时仓库内容没有任何变化。
