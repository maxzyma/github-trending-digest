**主线二：日增合计小幅上升，涨跌各半。** 16 项「今日」星数合计从 11-24 的 11,791 升到 12,214。上升的 8 项里，CLI-Anything 从 +790 涨到 +1,074，diagram-design 从 +620 涨到 +802，app-store-compliance 从 +761 涨到 +928，涨幅居前三。下降的 8 项里，Claude-BugHunter 从 +2,029 降到 +1,826，minimind 从 +828 降到 +727，last30days 从 +797 降到 +703。Claude-BugHunter 仍以近 800 星的差距领先。

**主线三：今天值得看的是几次版本发布和大批量重构。**

- **AutoClip** 11-24 发布 v1.6.0，首页新增「直播回放」入口，可导入 OBS、Twitch、YouTube、Kick、Discord 等渠道的录像剪高光；同时提供 CLI / MCP 包，可以接进 Agent 工作流。桌面安装包仍未做代码签名和 Apple 公证。
- **firecrawl** 一天合入 33 个提交，把 API 拆成可挂接的服务模块（hooks、请求 schema、扩展路由），并把自托管版内置的 LLM 提供方收窄到 OpenAI 兼容接口和 Ollama（#6037）、内置搜索收窄到 SearXNG 和 DuckDuckGo（#6038）。自托管用户升级前要核对自己用的提供方是否还在。
- **last30days** 在 11-24 白天又合入 9 个 `security:` 提交（#1588 至 #1596 一带），覆盖子进程命令行注入、子进程环境变量泄露密钥、Windows 批处理注入和多处 SSRF，另有约 20 个数据源解析修复。最新版本仍是 11-22 的 v4.6.0，这两轮加固都还没有进入正式版本。
- **opensre** 连续第二天发版（v0.1.2026.11.25），新增 Grafana、Datadog、PagerDuty、AWS 的官方 MCP 服务器预设（#7095），并把 Sentry、PostHog 的 MCP 连接接成带权限门的 Agent 工具（#7094）。

**主线四：榜单解读提醒 — 名次六天没动，排序不跟当日星数走。** cursor/plugins +360 排 #5，Ghost Downloader +1,092 排 #15。superpowers、CLI-Anything、minimind 这三个今天增量都在 700 星以上，但从 11-24 起都没有新提交，热度来自持续传播而不是新版本。app-store-compliance 的 subscribers 只有 14 个，对 5,897 星仍偏少；它这一天合入了二十多个安装器和校验修复，维护是活跃的，独立用户反馈还要继续看。下文累计增量按 11-20 首次记录计算。
