**主线二：Agent 工具收紧权限 — 求职框架、Claude Code、Orca 同一天调整审批规则。** ai-job-search 10-19 发布 v1.7.3。发布说明写明，有一份由 AI Agent 做的公开审查认为按默认配置在本机使用不安全，作者认可了这一点：技能声明的权限不再超出 `settings.json` 允许的范围，`settings.json` 自带的 deny 规则在任何权限模式下都生效，禁止 `curl`/`wget` 上传、`scp`、`ssh` 和读取 `.env`；读职位信息的几个 Agent 只能读取和搜索，不能写文件；职位页面进入模型前要先过一道检查，去掉隐藏 HTML、零宽字符和看起来像指令的文字。Claude Code 同日的 v2.1.304 允许 mod 把某次工具调用标成“必须由人批准”，在无人可问的场合直接拒绝，并给 `rm -r` 挂载盘或顶层目录补上确认提示。Orca 则在全局 Agent 权限开关里加入 Auto 档（#30677）。对使用者来说，这类变化会直接改变“哪些操作会被拦下来问我”，升级前值得看一眼发布说明。

**主线四：非 Agent 方向 — ComfyUI 日增破千，教育数据和金融模型各占一席。** ComfyUI 日增从昨天的 154 跳到 1,011，上升 9 位。10-19 的 v0.42.1 修复了 MOSS-image 模板崩溃，之后又合入 FLUX 3 视频节点的 2K/4K 分辨率（#17200）、ClarityAI 视频放大节点（#17192）和 HeyGen 声音克隆与语音合成节点（#17043），合作方节点继续往视频和语音扩展。新面孔 os-taxonomy 是儿童教育公司 Marble 开放的知识点图谱，10-19 刚合入一批理科和数学教学研究记录。Kronos 8-13 之后首次回榜，代码自 4 月以来没有新推送，但 issue 区 10-19 仍有用户提交自己的回测结果。

## NEW 首次上榜

### [withmarbleapp/os-taxonomy](https://github.com/withmarbleapp/os-taxonomy) — NEW ⭐ 6,164（+284）| JavaScript（JSON 数据集）| 信源：中

**它是什么**: 一张“小学阶段孩子要学什么、按什么顺序学”的知识地图，由儿童教育公司 Marble 开放，名为 Marble Skill Taxonomy。它把 8 个学科拆成 1,591 个最小知识点，比如“组句”“恒星的视亮度”。每个知识点写明适用年龄、怎样算学会、可以怎么提问检验。知识点之间有 3,225 条“先学会 A 才能学 B”的依赖关系，并标注它们对应美国 Common Core、NGSS 和英国国家课程中的哪些条目。

**解决什么问题**: 现有课程标准大多是按年级平铺的条目清单，不说明知识点之间的先后关系；做教育产品的团队通常要自己整理这张依赖图，或者用商业产品里封闭的版本。这个仓库把它做成可以直接读取的 JSON 图谱，家长、教育 App 和 AI 家教都可以拿来当骨架。

**谁在用、怎么用**（来自 Issues/X）:
- 社区工具：#12 征集基于这份数据做的工具，#16 是一个在浏览器里追踪孩子学习进度的工具。
- 补内容：外部 PR #20 补饼图知识点，#9 修复跨平台校验和问题。
- 扩展用途：#24 询问能否扩展到自定义领域；X 上有独立开发者做可视化、对接澳大利亚课程。

**社区怎么评价**:
- 正面: 数据结构清楚、可直接用；创始人 Lionel Mora 在 X 上称开源 48 小时内获得 90 万次浏览和 2,300 星（作者自报数字）；@omarsar0 做了可视化转发。
- 负面: #18 指出部分依赖关系说不通，例如“在逆境中成长”依赖“20 以内加减法熟练”，并追问依赖关系的依据；#22 质疑 9–10 岁数学知识点和课程标准对得不全。
- 健康度: 43 subscribers，星数与 subscribers 比约 143:1；1,006 fork，对数据集来说比例偏高，说明确实有人下载使用；open issue 13；提交集中在两名维护者（15 次、7 次），外部贡献 1 次。10-19 一天合并 #30、#31、#32、#35，修正年龄错位的依赖关系并加入教学研究记录。HN 只有两帖，最高 2 分；Reddit 未检索到讨论。

**风险与争议**:
- **compliance**: 授权分层。数据库部分用 ODbL 1.0，修改或扩展后的数据库须按同样协议开放；作者撰写的文字用 CC BY-SA 4.0；Common Core 部分限定用途，NGSS 等标准只给编号不给原文。商用前需读仓库里的来源与授权说明。
- **stability**: README 写明这些记录由 AI Agent 生成，经过另一个 Agent 抽检；教学建议未经实证验证，#18 的错误依赖说明质量需要使用方自行把关。
- **bus_factor**: 维护集中在 Marble 的两名成员。

**技术备注**: 纯数据仓库，主体是 JSON 文件和校验脚本，版本 v1。依赖关系是有向无环图，每条边标注 `hard`/`soft` 并附一句理由。本次回流的直接触发事件未找到，可能与 10-19 的数据更新和 10-17 的 HN 帖有关，属推断。
