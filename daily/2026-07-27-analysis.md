## 本日主线

**主线一：榜单地图 — 抗审查/去中心化通信突起为最强信号，AI agent 工具仍占最大项目数，基建老项目集中回流。** 今日 17 项可分四组：① **抗审查 / 去中心化通信**（4 项，今日最强主线）——permissionlesstech/bitchat（NEW 榜首，蓝牙 mesh 离网聊天）、permissionlesstech/bitchat-android（NEW，同项目 Android 端）、amnezia-vpn/amnezia-client（NEW，自托管 VPN 客户端，刚发 5.0）、block/buzz（↓2，基于 Nostr 的人机协作平台）；② **AI agent / 编码工具生态**（项目数最多，7 项）——citrolabs/ego-lite（↑3，给 agent 用的浏览器）、pingdotgg/t3code（RE，编码 agent 的 Web GUI）、alibaba/open-code-review（=，阿里 AI 代码审查 CLI）、pbakaus/impeccable（RE，给 AI harness 的设计技能包）、anthropics/claude-cookbooks（RE，Claude 官方 recipe 集）、andrewyng/aisuite（RE，多 provider 统一接口）、CoreBunch/Instatic（RE，agentic 自托管 CMS）；③ **成熟开发基建首入/回流**（5 项）——nodejs/node（NEW 首入 tracker）、jenkinsci/jenkins（NEW 首入 tracker）、yorukot/superfile（NEW，Go 终端文件管理器）、OtterMind/Chat2DB（NEW，AI 数据库客户端）、Pumpkin-MC/Pumpkin（↓10，Rust 版 Minecraft 服务端）；④ **金融基础模型**——shiyu-coder/Kronos（↓7）。今日的结构变化是：agent 仍是最大项目盘，但真正驱动榜首和话题度的是通信自由与抗封锁。

**主线二：今日最有分量的事件是 bitchat 因印度下架令登上榜首 —— 一次典型的 Streisand 效应。** permissionlesstech/bitchat（30,492 ⭐，今日 +1,166，Swift）是 Jack Dorsey 发起、现由社区组织维护的蓝牙 mesh 聊天应用，完全不依赖互联网。7 月 23 日印度 I4C 依 IT Act 79(3)(b) 要求 GitHub 在 3 小时内删除 permissionlesstech 的三个仓库，Dorsey 于 7 月 24 日在 X 公开该通知，随后项目被镜像到去中心化的 Radicle 上。三条相关 HN 主贴分别拿到 536 分/435 评（印度下架）、253 分/142 评（Radicle 镜像）、517 分/292 评（Bitchat for Gaza），加上 2025 年首发的 795 分/424 评，是今日 grounding 最扎实的项目。同一事件也把 Android 端（#15，6,741 ⭐）一起带上榜。真实使用同样有据：印度 7/17~23 下载 9.1 万+（占全球约 85%，DAU 超 33 万）、尼泊尔约 5 万、马达加斯加约 7 万，牙买加飓风断网期一度登顶。**但读者要分清"抗审查叙事"与"密码学成熟度"**：项目长期宣称 secure 却缺独立审计，尚未达到 forward secrecy，#1107（Nostr relay DM 加 double-ratchet）、#1487（peer ID 轮换）都还在补，Block 自家工程师曾提 PR 要求加免责警示；#1364 更暴露过用户误以为 mesh 频道私密的真实误用风险。

**主线三：抗封锁不是单点事件 —— Amnezia 同日发布 AmneziaWG 2.0，协议层对抗进入新阶段。** amnezia-vpn/amnezia-client（13,352 ⭐，C++）在 7/25–26 连发 5.0 大版本，主线是 AmneziaWG 2.0（Signature Packets、Custom Protocol Signature、Advanced Padding、Ranged Headers）。值得注意的是官方明确宣告 Cloak / Obfs4 / Shadowsocks / AmneziaWG 1.0 在强审查国家已经失效——这是一个来自实战一线的可用性判断，背景是 Roskomnadzor 夏季近乎全量封锁未识别 UDP 流量、2025-10 第 1667 号法令、以及 Apple 已从俄区下架 60+ VPN 应用（含 Amnezia 自己）。它的工程可信度高于多数榜单项目：通过 7ASecurity 三次独立审计（2022/2024/2025），AmneziaWG 更被 Windscribe 等商业 VPN 采纳为原生协议——这是极少数被第三方厂商复用的开源抗审查协议。代价是 948 个 open issues（vs 仅 503 closed）的真实积压，以及 5.0 多平台构建暫缺。

**主线四：AI agent 工具盘的形态从"新爆款"转向"存量回流"。** 今日 agent 相关 7 项里，5 项是 RE 老面孔（t3code、impeccable、claude-cookbooks、aisuite、Instatic），只有 ego-lite（↑3）和 open-code-review（=）延续上周热度，没有出现新的 agent 黑马。其中 impeccable 值得单独一提：自 6-02 首次上榜以来从 32,767 ⭐ 涨到 50,740 ⭐（净增约 1.8 万），是本季度增速最猛的 agent 周边项目之一；aisuite 则相反，1 个月只涨约 1,000 ⭐，且核心库长期停更、定位已漂移。对读者的意义：agent 工具链正在进入分化期，值得从"是否在榜"转向"是否还在被真实维护"。

**主线五：榜单解读提醒 — 两个需要谨慎解读的样本。** 其一，**OtterMind/Chat2DB（27,159 ⭐）的"开源"表述与实际许可存在落差**：项目从 alibaba/Chat2DB → chat2db → CodePhiliaX → OtterMind 几度易主，5.3.0 起社区版由 Apache-2.0 改为"Apache 2.0 + 附加条件"的 source-available（禁止对外服务/嵌入/OEM/二进制分发），GitHub 已标为 NOASSERTION，而 README 仍在宣传 open-source；issue 区里 #1550「一个收费的软件 为什么要开源」、#1375「我买的 pro 版本 更新一下就没了?」等抱怨集中在商业化，另有 #1914 报告 34 处 SQL 注入且仍是 `needs/reproduction`。其二，**shiyu-coder/Kronos（34,203 ⭐，今日 +321）的最后一次代码推送是 2026-04-13**，已停更 3 个半月却仍在持续吸星，这类"停更但持续上榜"的项目不宜按活跃项目解读。另外 nodejs/node（3,001 subscribers）、jenkins（889 subscribers）今日增量分别只有 +36 和 +18，属 trending 算法波动性回流，不代表社区出现新事件。

### [permissionlesstech/bitchat](https://github.com/permissionlesstech/bitchat) — NEW ⭐ 30,492（+1,166）| Swift | 信源：强

**它是什么**: 一个完全不需要互联网的聊天 App。手机之间直接用蓝牙互相连接、并且能多跳中继（最多 7 跳），所以在断网、关网、没有信号的地方，一群人依然可以互相发消息。由 Jack Dorsey（Twitter 联合创始人）做出原型，现在由社区组织 permissionlesstech 维护，风格上刻意做成"IRC 味"。

**解决什么问题**: 以前遇到政府断网、自然灾害断网、或者演唱会/机舱里没信号，通信就直接归零。bitchat 把手机本身变成中继节点，不依赖运营商、不依赖任何服务器、不需要手机号注册。这也让它天然成为抗审查工具——审查方无法通过封 IP 或封域名来阻断它。

**谁在用、怎么用**（来自 Issues / HN / 媒体 / Sensor Tower）:
- 断网抗议现场：印度 7/17~23 下载 9.1 万+（占全球约 85%，DAU 超 33 万）、尼泊尔约 5 万、马达加斯加约 7 万，印尼、乌干达、伊朗抗议期间同样出现下载激增。
- 灾害通信：牙买加飓风 Melissa 断网期间一度登顶当地应用榜；社区还实测过音乐节、机舱内点对点通信。
- 社区正在补协议短板而非只刷星：#1487 peer ID 轮换（隐私加固）、#1107 为 Nostr relay DM 加 double-ratchet、#1472 courier wire format 黄金测试向量。

**社区怎么评价**:
- 正面: HN 讨论极强且是多次独立爆发——2025-07-07 首发 795 分/424 评、2026-07-24「印度要求 GitHub 下架 bitchat」536 分/435 评、2026-07-25「已上 Radicle」253 分/142 评、「Bitchat for Gaza」517 分/292 评。fork 率极高（4,748 forks / 30,492 stars ≈ 15.6%），说明真在被二次构建。
- 负面: #1438 courier spray 在 handover 被拒时会丢消息副本；#1364 会话恢复出错，且用户此前会误以为 mesh 频道是私密的（UI 未说清）；#508 与 Meshtastic 互通被长期请求（19 评）却未落地。
- 健康度: 30,492 ⭐ / 284 subscribers（≈107:1，对爆款开源属常态）、open issues 49、contributors 49、最后 push 2026-07-26，v1.5.4→v1.7.0 集中在 7 月上旬发布，维护活跃。

**风险与争议**:
- **安全审计缺位**: 核心红旗——长期宣称 secure 却无独立第三方审计，尚未达到 forward secrecy（需 X3DH+double ratchet 或 MLS），Block 自家工程师曾提 PR 要求加免责警示。
- **compliance**: 印度已下发下架令，乌干达在选举前有封禁威胁，高危地区用户存在实际法律风险。
- **privacy**: geohash 重复使用可被用于定位；mesh 频道的公开性此前未在 UI 上明确告知（#1364）。
- **stability**: 消息投递存在已知丢失路径（#1438）。
- **dependency**: 依赖 Nostr 独立 relay 的可持续性，以及 Apple 应用商店规则。

**技术备注**: Swift 实现，BLE 多跳 mesh + X25519/AES-256-GCM，geohash 频道走网络；License 为 Unlicense（公共领域，便于镜像分发，与抗封锁场景相关）。创建于 2025-07-04。

## 如何理解今天的热度信号

今天有一个不常见的好样本：**抗审查类项目的热度是"事件驱动 + 可验证使用"，与"传播驱动 + 无独立采用证据"形成清晰对照**。bitchat 的 star 增长背后能追溯到具体的政府通知（印度 I4C 7/23 下架令）、四次独立的 HN 高分讨论、以及第三方下载量数据；Amnezia 的热度背后是一次实质版本发布和三次独立安全审计。这两个项目的可信度不来自 star 数，而来自"外部世界能被独立核验的痕迹"。

对照来看，今日短龄高增速项目（ego-lite 三天近三倍、Instatic 一月近三倍、impeccable 两月 +1.8 万）的共同特征是：star 曲线极陡，但 subscribers、open issues、HN/Reddit 独立讨论都没有同比例跟上。这不等于项目不好——impeccable 有真实的工程底盘——但意味着现在还看不到"被广泛真实采用"的证据。

关于 stars/subscribers 比值，今日再次说明它不能单独用作判据：nodejs/node 39:1、jenkins 29:1、bitchat-android 78:1、aisuite 87:1 都在正常区间，而 superfile 369:1 只是成熟 TUI 工具的结构性偏高。真正值得警惕的是**组合信号**：短仓龄 + 单一维护者 + 高比值 + 外部独立讨论缺失（ego-lite、Instatic），或者**停更 + 持续吸星**（Kronos 停更 3 个半月仍日增 321）。

最后，许可与治理变更是今日容易被忽略的一类风险。Chat2DB 的 README 仍写着 open-source，但社区版自 5.3.0 起已改为限制对外服务/嵌入/OEM 的 source-available 许可，且仓库几度易主。如果你打算把这类工具嵌入商业产品，star 数完全不能替代对 LICENSE 原文的核对。
