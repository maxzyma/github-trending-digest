- 健康度: 13,498 ⭐ / 117 subscribers ≈ 115:1，对 2018 年建的老仓属结构性偏高，不能单凭此判 vanity；open issues 104，其中 bug 标签仅 9 个；约 75 位贡献者，前 4 人（Smart Code 公司员工）贡献占绝大多数。HN 近 6 个月仅两条 2 分 0 评论帖；X 官方号 16.8K 粉，第三方传播以"Stremio + Torrentio = 免费 Netflix"类病毒帖为主；Reddit 上 r/Stremio、r/StremioAddons 是主要社区（本次抓取被拦，转述未验）。

**风险与争议**:
- **compliance**: 项目本身合法且 GPL-2.0，但实际使用高度依赖 Torrentio 等抓 torrent 的社区 addon；2026 年 1 月被 Google Play 下架，iOS 只能侧载。
- **privacy**: 自建 streaming server 无鉴权（#1718、#252），#1414 刚补的"不可信 URL 二次确认"属被动补洞。
- **dependency**: Web 版体验强绑定第三方 addon 可用性，Torrentio 一挂用户就认为 Stremio 坏了。
- **bus_factor**: 贡献集中在 Smart Code OOD 的 4 名员工。

**技术备注**: React 前端，核心逻辑来自 Rust 编译成 WASM 的 stremio-core，GPL-2.0。成熟项目，未 clone。
