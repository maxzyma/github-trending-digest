## NEW 首次上榜

### [Renhuai123/ziwei-doushu](https://github.com/Renhuai123/ziwei-doushu) — NEW ⭐ 7,076（+546）| TypeScript | 信源：中

**它是什么**: 一套紫微斗数（中国传统命理术数）排盘程序。输入出生时间和性别，自动排出命盘、四化等结构，并附带倪海厦《天纪》体系的格局知识库和古籍原文。作者还公开了两批大规模解读数据：v3 为 51.8 万张命盘，v4（10-15 发布）为 67.5 万张命盘 × 13 个维度，共 877 万段解读，解压后约 56.6 GB。

**解决什么问题**: 以前想做命理类应用或研究，开发者要自己实现排盘算法、整理古籍和解读文本。这个仓库把排盘代码、知识库和批量生成的解读打包开源，可以直接拿来做排盘工具、命理 App，或作为训练和校验大模型的语料。注意它是作者商业站 metisziwei.com 的开源部分，AI 解读、断语库、后端和付费功能不在仓库里。

**谁在用、怎么用**（来自 GitHub Issues 与衍生仓库）:
- 数据集使用者：有人用样本数据做交叉校验，发现时辰参数被直接当成 iztro 的时辰序号传入，导致部分样本错位，作者承认后修正（#26）。两个数据集的 release 下载量合计约 7 万多次，比星数更能说明实际在用。
- 二次开发：GitHub 上已有基于它的 AI 命盘工作台类衍生项目；也有用户询问数据集能否商用（#13），以及本地部署问题。

**社区怎么评价**:
- 正面: 排盘结构完整，数据集规模大、授权写得细（代码 MIT，数据 CC BY 4.0 可商用，倪海厦原话单列为 CC BY-NC-SA 4.0）。
- 负面: 有用户直接反馈“不准”（#22）；有人质疑解读数据主要由机器生成、缺少真人校验（#7）。仍开着的 issue 指出排盘函数会静默忽略经度，导致真太阳时校正不生效（#45），无效性别值会被当成女性处理（#38），修复 PR 尚未合并。
- 健康度: stars/subscribers 约 244:1；open issue 8 个（含 PR）；51 次提交几乎全部出自作者本人。HN、X、Reddit 及 V2EX、知乎等中文技术社区都没检出独立讨论，传播主要来自作者在小红书、抖音的自我推广（转述未验）。

**风险与争议**:
- **compliance**: 命理内容在部分平台和地区有内容监管要求；数据集能否商用的问答中作者口径前后有过变化（#13），现以 README 与 DATASET-LICENSE 为准。
- **stability**: 排盘口径类 bug 仍有未合并修复（#38、#45），对结果准确性敏感的使用场景需自行校验。
- **bus_factor**: 单作者维护，核心断语库与 AI 解读闭源，开源部分的演进取决于商业站点。
- **vanity**: 星数增长快，但外部技术社区几乎没有讨论；“877 万段解读”是批量生成的规模，不代表解读质量。

**技术备注**: TypeScript / Next.js，排盘基于 iztro 与 lunar-javascript；仓库创建于 2026-05-01，10-24 仍在推送，最近 release 为 v4.0（10-15）。
