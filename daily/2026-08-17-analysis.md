## 新上榜项目

### [basecamp/omarchy](https://github.com/basecamp/omarchy) — NEW ⭐ 25,432（+270）| Shell | 信源：强

**它是什么**: 一套"装完就能直接用"的 Linux 桌面环境，由 Ruby on Rails 作者 DHH 和 37signals 团队维护。它建立在 Arch Linux 和平铺式窗口管理器 Hyprland 之上，但用户不需要接触这两者中的任何配置——下载一个 ISO，装完开机，字体、配色、快捷键、状态栏、终端、编辑器、截图工具、剪贴板历史、通知系统全部已经调好并互相协调。定位上它更接近"macOS 的一种替代品"，而不是"一个供你继续折腾的起点"。项目名 Omarchy = Opinionated + Arch。

**解决什么问题**: 平铺式窗口管理器（Hyprland、i3、sway 这类用键盘而非鼠标管理窗口的方案）在效率上很有吸引力，但代价是要自己拼装一整套外围组件：状态栏一个项目、启动器一个项目、通知守护进程一个项目、锁屏一个项目、亮度/音量提示又是一个项目，每个都有自己的配置文件格式和主题系统，配色要手工同步七八处，任何一个组件升级都可能破坏整体。这个过程通常要花掉几天到几周，而且长期需要维护。Omarchy 的做法是**替用户做完所有选择**：所有组件预先集成、主题统一（v4 把主题色位从 8 扩到 24，btop/nvim/vscode 的配色可以自动生成）、升级由 `omarchy` 命令统一管理。v4 更进一步，把外围组件的拼装问题从根上消掉了——不再是"八个项目协同"，而是一个进程加插件。

**谁在用、怎么用**（来自 Issues/HN/X/厂商公告）:
- 场景 1: **开发者主力工作站**。37signals 全员采用是最直接的背书；Framework、Dell XPS 的官方博客、以及设备管理厂商 Fleet MDM 的支持公告构成第三方证据链。DHH 公布的数字是月装机约 15 万台、单月分发流量 1 PB。
- 场景 2: **旧 Intel Mac 的二次利用**。社区反馈集中在 pre-M 系列 Mac（含 T1/T2 芯片机型）装 Omarchy 后重新可用，这是 issue 区硬件类讨论最密集的一块，例如 #1806（MacBook Pro 2020 的 WiFi 与睡眠问题，33 条评论，长期未决）。
- 场景 3: **想用平铺 WM 但不愿投入配置时间的运维与 SRE**。v4 的控制面板（音频、蓝牙、网络、显示、电源各一个快捷键）和 networkmanager 迁移就是冲这类"要能直接调，不想改配置文件"的用户去的。

**社区怎么评价**:
- 正面: HN 上讨论密度极高且分数很高——Cloudflare 赞助 Ladybird 与 Omarchy（776 分 / 483 评论）、"Omarchy Is Out"（215 / 135）。正面意见集中在"开箱即用的 Hyprland 铺路石"和老硬件复活两点。
- 负面: 争议同样在 HN 上成规模，主线是**定义之争**——"Omarchy Is Not A Distro"（186 分 / 168 评论）、"A Word on Omarchy"（139 / 94），批评者认为它本质是"Arch + DHH 的 dotfiles"，配不上"发行版"的说法；另一条批评是默认捆绑了 1Password、Spotify、Claude、Grok 和 X 的快捷方式，把专有服务写进了一个开源桌面的默认体验。
- 健康度: 25,432 ⭐ / 139 subscribers（约 183:1）/ 2,596 forks / 748 条 open issue 与 PR（其中 issue 362 条，历史闭合率 87%）。贡献者名义上过百，但分布极度集中：dhh 4,481 commits、ryanrhughes 696，第三名只有 19。MIT license，2025-06 建仓，默认分支已切到 `quattro`。

**风险与争议**:
- **bus_factor**: dhh 一人约占 80% 提交，第二名贡献者之后断崖式下跌，项目的技术方向与维护节奏几乎完全绑定在个人身上。
- **stability**: v4 是整壳重写，回归面明显——#6572（Quattro 重写中丢失的 D-Bus idle-inhibit 需重新实现）、#7203（Vantablack 主题图标在 4.0.0 失效）、#7195（通知在所有显示器上重复渲染）、#7199（全屏视频触发屏保）都是 4.0.0 后新报的。想升级的现有用户不妨等一个 4.0.x。
- **dependency**: 默认体验捆绑 1Password、Spotify、Dropbox、Tailscale 及多家 AI 服务的快捷入口，其中若干依赖第三方 API 与专有客户端；同时 v4 把 Omarchy 内部件从 git 迁到系统包管理，升级路径与上游 Arch 仓库的耦合变深。
- **社区政治化**: 围绕作者本人与 Framework/Lunduke 事件的争论显著抬高了这个项目的非技术性传播量。判断它是否适合自己时，这部分声量不构成技术证据。

**技术备注**: Shell 为主，配置层在 v4 全面转为 Lua 以兼容 Hyprland 0.56；新桌面 shell 基于 Quickshell（QML/Qt），单进程加载插件；仓库内含 `manual/`（权威文档源，镜像到 learn.omacom.io）、`migrations/`（版本迁移脚本）、`agents/skills/`（编码 agent 技能）。安装方式为官方 ISO（4.0.0 约 6 GB），现有安装可经 `Update > Omarchy to Quattro` 就地升级。
