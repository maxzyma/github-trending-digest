## 本日主线

**主线一：榜单地图 — 8 项无新面孔，前四名原位不动。** 今日可分 4 组：

- **原生程序、逆向与创作工具**（3 项，包揽前三）—— `morluto/rea`（=，榜首，+25,599）应用与二进制逆向、`boykopovar/AnyPS5`（=，#2，+3,952）PS5 游戏移植、`storytold/artcraft`（=，#3，+2,957）AI 出图出视频工作台

和 10-11 相比，昨天的 13 项留下 5 项。退场的 8 项里有 4 个 skill 与插件包（`mattpocock/skills`、`context-mode`、`knowledge-work-plugins`、`andrej-karpathy-skills`）和 3 个成熟框架（TensorFlow、Transformers、Flutter），以及 `ppt-master`。昨天占 5 席的 skill 赛道今天只剩 `diagram-design`；周末一起回来的成熟框架，今天只有 PyTorch 留下。

**主线二：前三名仍是本地运行的重型工具 — 都在高频提交，但节奏不同。** `rea`（#1）按 API 一天从 77,310 涨到 107,829 星，10-11 发布 6.4.0 之后又合入至少 100 个提交，方向是把已有能力做扎实：大型 Electron 包里追踪被包装过的 IPC 调用（#1874）、保留 macOS 通用二进制的容器信息、减少 Windows 下的启动文件读写（#1996）。`AnyPS5`（#2）继续以社区 PR 为主，夜里合入的有从宿主系统取随机熵（#4200）、拒绝对非线程栈内存调用 `mprotect`（#4169）、修复 Windows 下 `select` 轮询（#4021）；open issue 和 PR 从昨天的 345 个涨到 620 个，参与者增加很快，正式版本仍停在 9-28 的 v0.1.1。`artcraft`（#3）的纯 Rust 桌面端 10-11 加入出图服务商选择，可以用 Midjourney 或 fal 生成。

**主线三：三个回榜项目各有来由 — 一个是新版本，一个是新闻，一个原因不明。** `gods-eye-view` 10-03 发布 v0.2.0 和 v0.2.1，加入 MCP 服务，约 40 个工具覆盖航班、船舶、卫星、地震、山火、摄像头、天气等数据，在 Claude Desktop、Codex 和 ChatGPT 桌面端里回答会直接弹出可交互的地球面板。`Apollo-11` 的回榜与新闻同步：HN 10-08 有两条帖子转载《卫报》和 BBC 的报道，为阿波罗 11 号编写软件的 Margaret Hamilton 去世，享年 90 岁；10-11 又有一条讲这份源码的视频帖。`airllm` 最近一次功能发布是 9-05 的 v4.0.0（流式 LoRA 训练），之后的提交都是每天自动刷新 star 历史图，HN 上 9 月以来也没有相关讨论，今天回榜的直接诱因找不到。

**主线四：榜单解读提醒 — 榜首的星数增速远快于关注者增速。** `rea` 的 subscribers 从昨天的 245 升到 341，星数与 subscribers 比约 316:1；fork 数已有 23,869。提交和发版的频率是真实的，但一天 3 万星主要说明传播面很广，实际在用的人有多少，要看后续外部 issue 和使用反馈。`airllm` 回榜期间仓库没有代码更新，宜理解为老项目被重新收藏，不代表有新进展。
