## 新上榜项目

### [floci-io/floci](https://github.com/floci-io/floci) — NEW ⭐ 28,850（+482）| Java | 信源：强

**它是什么**: 一个装在自己电脑上的"假 AWS"。你的程序以为自己在调用 S3、Lambda、RDS 这些亚马逊云服务，实际请求发到本机的 floci，开发、测试和 CI 都不用连真云、不花钱。

**解决什么问题**: 以前大家用 LocalStack 社区版做这件事。LocalStack 2026 年 3 月停止免费提供社区版，要求 auth token，安全更新也冻结了。floci 不设账号和付费功能门槛，SDK、CLI、Terraform、CDK 照旧指向 `http://localhost:4566`，换掉镜像就能迁过来。Lambda、RDS、EKS 这类服务会起真实容器，不只是返回假数据。

**谁在用、怎么用**（来自 Issues/HN/X/Testcontainers）:
- 场景 1: 在 CI 和集成测试里替换 LocalStack。Testcontainers 官方已经收录 `testcontainers-floci` 模块；#4527 记录了 CI 里 Docker 测试因 ECR Public 限流而失败的问题。
- 场景 2: 用户在做贴近生产的测试，提出故障注入和请求日志（#4623）、CloudFormation 属性一致性（#6606）这类进阶需求。
- 场景 3: 本地验证 Terraform/CDK、练习 AWS。X 上 midudev 的西语介绍帖有约 12.5 万浏览，西语社区用户较多。

**社区怎么评价**:
- 正面: 9 月的 HN 帖（220 分、49 条评论）以正面为主，看重轻量、适合 CI。2,133 个已关闭 issue、累计 5,111 个 PR，10 月发了 2.2.0、2.3.0、2.4.0 三个版本。
- 负面: 3 月首发 HN 帖（292 分、95 条评论）有人质疑代码像 AI 生成、行为和 AWS 有出入、没有 AWS 背书难以持续。打开的 bug 集中在与真实 AWS 行为不一致，例如 IAM/STS 返回值（#6042）、EC2 默认 VPC 资源 ID（#7306）。Reddit 只有官方开的 r/floci。
- 健康度: 88 个关注者，星数与关注者之比约 328:1，偏高，但 issue、PR 和发版节奏说明有真实使用。打开的 issue 127 个、PR 43 个，11-04 仍在合入修复。

**风险与争议**:
- **stability**: 模拟器和真实 AWS 行为有差异，本地测试通过不等于线上也一样。
- **bus_factor**: 靠创始人带动、AI 辅助开发，服务覆盖扩张很快，还扩到了 Azure、GCP，长期维护压力大。
- **vanity**: 外部传播以 KOL 转发为主（"比 LocalStack 快 250 倍"），独立开发者的长文评测少；README 里 24 ms 冷启动等数字没有第三方验证。

**技术备注**: Java，MIT 许可，Docker 运行，默认端口 4566，自带 `/_floci/ui` 管理界面。仓库由作者个人账号迁入 floci-io 组织；姊妹项目 floci-az、floci-gcp 分别模拟 Azure 和 GCP。

### [spotify/portal-ai-plugins](https://github.com/spotify/portal-ai-plugins) — NEW ⭐ 3,059（+91）| TypeScript | 信源：中

**它是什么**: Spotify 官方的编码 Agent 插件包。Spotify Portal 是 Spotify 基于开源 Backstage 做的商业版开发者门户，记录公司里有哪些服务、谁负责、运行是否健康。这套插件让你在 Claude Code、Codex、Cursor 或 pi 里用自然语言查这些信息，或者直接触发门户里的操作。

**解决什么问题**: 以前要切到门户网页查服务归属和事故记录，再回编辑器干活。装上插件后，Agent 可以生成服务简报、调用 Portal Actions，还能用 Fleetshift 对一批仓库发起同样的改动并开 PR。附带的 shunt 插件只支持 Claude Code，把读大文件、生成样板代码这类活转给更便宜的模型，用来省 Claude 的 token。

**谁在用、怎么用**（来自 Issues/HN）:
- 场景 1: 已付费部署 Portal 的平台团队，在 Agent 里查服务目录、跑批量迁移。#16 反映安装文档缺少 Portal 后端地址说明，#25 报告 Portal CLI 拒绝有效登录令牌。
- 场景 2: 想用 shunt 省 token 的 Claude Code 用户。#10、#19、#26 都是 shunt 的 hook 输出格式不符合当前 Claude Code 校验、拦不住调用，0.2.0 仍未修好；#18 报告 Windows 下全部委派失败。
- 场景 3: 社区希望扩到更多宿主，pi 支持（#12）已经落地，Antigravity（#17）、VS Code（#14）还在请求中。

**社区怎么评价**:
- 正面: Spotify 工程博客《Portal by Spotify cut my Claude Code token usage by 90%》在 HN 拿到 278 分，把这个项目带进了开发者视野。
- 负面: HN 评论主流是质疑：Claude Code 自带的探索子代理本来就跑在便宜模型上，有人实测只省 5% 到 7%。博客的 90% 来自单个 Java monorepo 的四个场景，只针对大文件读取。X 和 Reddit 没有找到独立开发者的一手讨论。
- 健康度: 19 个关注者，星数与关注者之比约 161:1；13 个打开的 issue，没有正式版本，最后一次推送是 10-23。只有 3 位 Spotify 员工提交过代码，#13 说明 PR 只接受协作者。

**风险与争议**:
- **dependency**: 必须有 Spotify Portal 商业实例，shunt 还要开启 AiKA，个人开发者装了也用不起来。
- **stability**: hook 兼容问题反复出现，Windows 不可用，没有发布版本。
- **bus_factor**: 3 名内部贡献者，不接受外部 PR。

**技术备注**: Apache-2.0 许可，所有流程通过 `npx @spotify/portal-cli` 执行；同时提供 Claude Code、Codex、Cursor 和 pi 的插件清单。

### [Usagi-org/ai-goofish-monitor](https://github.com/Usagi-org/ai-goofish-monitor) — NEW ⭐ 16,472（+228）| Python | 信源：中

**它是什么**: 一个替你盯闲鱼的机器人。你用一句话说想买什么，它 24 小时刷新闲鱼上新，让 AI 看图片、描述和卖家信用，判断是不是真个人闲置、价格是否合适，符合条件就推送到手机。

**解决什么问题**: 在闲鱼上捡漏，原本要人工反复刷新，在大量商家挂卖里一条条筛。这个工具把刷新和初筛交给程序和多模态模型，支持企业微信、Bark、Telegram、ntfy 和 Webhook 通知，带网页管理后台、定时任务、多账号和代理轮换。

**谁在用、怎么用**（来自 Issues/中文社区）:
- 场景 1: 在 NAS 或 VPS 上长期蹲显卡、数码产品的低价上新，什么值得买和 cpolar 博客都有部署教程。
- 场景 2: 用户在要更细的筛选和自动化：#479（13 条评论）要求加黑名单剔除无关商品，#506 和 PR #474 想要自动下单。
- 场景 3: 接入不同大模型。置顶帖 #308 专门汇总模型接口问题，有用户免费额度用完后改用本地 Ollama。

**社区怎么评价**:
- 正面: 作者回复积极，2.5 版（10-09）修了推送失败判定等问题；fork 2,851 个，衍生项目里有人专门加了账号健康检测。
- 负面: 闲鱼风控是最集中的问题，#465 触发反爬验证后程序直接终止，#339 用 Docker 部署两个账号一启动就被判为机器人；大模型调用报错也多。HN 和 Reddit 无讨论，X 上以中文资源号转发为主。
- 健康度: 56 个关注者，星数与关注者之比约 294:1；32 个打开的 issue、10 个打开的 PR。主要作者提交 397 次，其余贡献者都不超过 25 次；10-10 以后没有新推送。

**风险与争议**:
- **compliance**: 闲鱼用户协议禁止用程序未经授权获取平台数据，违约可能被限制功能或封号。
- **stability**: 风控触发后任务直接停止，项目内置多账号和代理轮换来应对，说明这是常态。
- **privacy**: 闲鱼登录 cookie 明文存在 `state/` 目录，网页后台默认账号密码是 `admin/admin123`，部署后要先改。
- **cost**: 多模态模型逐条看图，token 消耗快。
- **bus_factor**: 基本由一人维护。

**技术备注**: Python + Playwright，MIT 许可，推荐 Docker 部署；模型需支持图片输入，兼容 OpenAI 格式接口即可。
