## 本日主线

**主线一：榜单地图 — AI agent 协作/编码工具生态占最大盘，成熟开发工具老项目回流，AI/感知模型三线并存。** 今日 15 项可分三组：① **AI agent 协作 / 编码工具生态**（最大盘，7 项）——block/buzz（NEW 榜首，Block 开源的"人 + Agent 同体系"协作平台）、diegosouzapw/OmniRoute（RE，聚合 290+ provider 的 AI 网关）、alibaba/open-code-review（NEW，阿里 AI 代码审查 CLI）、ComposioHQ/awesome-claude-skills（NEW，Claude Skills 精选清单）、earthtojake/text-to-cad（NEW，面向 agent 的 CAD 技能包）、agegr/pi-web（NEW，pi 编码 agent 的 Web UI）、citrolabs/ego-lite（NEW，AI agent 浏览器）；② **成熟开发工具 / 老项目回流首入**（5 项）——jellyfin/jellyfin（RE，FOSS 家庭媒体服务器）、Automattic/harper（NEW，离线语法检查器，WordPress 母公司背书）、likec4/likec4（NEW，架构即代码）、Pumpkin-MC/Pumpkin（NEW，Rust 重写的 Minecraft 服务端）、chrislgarry/Apollo-11（RE，阿波罗 11 号 AGC 源码）；③ **AI / 感知模型**（3 项，均 RE 老面孔）——ruvnet/RuView（WiFi 空间感知）、shiyu-coder/Kronos（金融市场基础模型）、koala73/worldmonitor（全球情报看板）。agent 相关合计占榜单近半。

**主线二：今日最有分量的信号是 Block（Jack Dorsey）开源 buzz —— 把人和 Agent 放进同一身份体系的协作平台。** block/buzz（7,040 ⭐，今日 +2,162，Rust）由 Square/Cash App 母公司 Block 于本周开源，基于 Nostr 协议，被外媒定位为"Agent 时代的 Slack + GitHub 替代品"：团队聊天、Git 托管、AI Agent 共用一套身份，人和 agent 都是"平等成员"，Block 内部已作首个客户。它的 grounding 在传播端很强——外媒转载帖 HN 374 分 / 331 评、Dorsey 亲自发帖背书；但也暴露两处待解：其一，宣称"去中心化"而每个 workspace 实际跑在单一 relay，名实存在落差；其二，多 Agent 跨频道的权限边界是整个赛道的公开未解难题，Block 自己的活跃 PR（#2537、#2582 锁 agent 权限）也印证了这一点。这是今日对 AI builder 最值得点开评估的方向性项目，但需区分"创始人光环 + 媒体传播"与"独立采用证据"。

**主线三：企业级开源"官方化"延续 —— 阿里 open-code-review 与 Automattic harper 同日在榜。** 今日两个有真实工程背书的企业开源件同框：alibaba/open-code-review（11,602 ⭐，Go）是阿里内部用了两年、覆盖 2 万+ 员工、检出百万缺陷后开源的 AI 代码审查 CLI，HN 284 分 / 73 评，核心争论在"高误报会被开发者忽略"，项目回应是刻意"重精确率轻召回率"；Automattic/harper（12,358 ⭐，Rust）是被 WordPress 母公司 Automattic 收购的离线隐私优先语法检查器，以 LSP 形态嵌入 Obsidian、VS Code、Neovim 等，100+ 贡献者、维护健康。两者都比短龄 agent 合集更经得起点开评估，但也各有边界（前者单核维护 + 依赖付费 LLM，后者仅支持英语）。

**主线四：榜单解读提醒 — 多个高 star/subscribers 比、短龄项目需结合社区 grounding 判断。** 今日短龄新项目里 citrolabs/ego-lite（1,706 ⭐，仓龄约 3 个月，比值约 243:1，单一贡献者，HN/Reddit 近乎零讨论）、earthtojake/text-to-cad（比值约 152:1，benchmark 复现被质疑）传播热度明显领先真实采用；RE 老面孔 worldmonitor（71,709 ⭐，161:1）、OmniRoute（27,289 ⭐，182:1）、RuView（85,247 ⭐）、Kronos（33,094 ⭐）继续以高比值、外部独立讨论偏薄的形态回流。这些不宜仅凭 star 数当作采用信号，建议结合 issue、HN/Reddit/X 足迹判断。

### [block/buzz](https://github.com/block/buzz) — NEW ⭐ 7,040（+2,162）| Rust | 信源：中

**它是什么**: Block（Jack Dorsey 旗下、Square/Cash App 母公司）开源的团队协作平台，把团队聊天、Git 代码托管和 AI Agent 装进同一套身份体系里——人和 Agent 都被当作"平等成员"参与协作。可以理解为"为 Agent 时代重做的 Slack + GitHub"。

**解决什么问题**: 现在人用 Slack 沟通、用 GitHub 托管代码，而 AI agent 是外挂进来的、身份和权限割裂。buzz 想让 agent 从一开始就是协作系统里的一等公民，减少团队对 Slack/GitHub 的依赖；Block 自己是第一个客户。

**谁在用、怎么用**（来自 HN / 媒体 / 仓库 PR）:
- Block 内部作为首个生产客户使用，目标是替换自身对 Slack/GitHub 的依赖；模型无关，可接 Claude Code、OpenAI Codex 及 Block 自家 goose。
- 团队当前主攻"Agent 权限边界"：PR #2537「lock internal agents to owner access」、#2582「Lock internal local agents to approved relays」显示安全模型仍在硬化中。

**社区怎么评价**:
- 正面: 外媒转载帖 HN 374 分 / 331 评，Dorsey 亲自背书，方向（agent 原生协作）被广泛认可。
- 负面: HN 批评"宣称去中心化，但每个 workspace 实际跑在单一 relay"；多 agent 跨频道权限/安全被指为全赛道未解难题。
- 健康度: 7,040 ⭐ / 39 subscribers（≈180:1），open issues 507（多为内部 PR），核心贡献者 5-6 人全部为 Block 员工，版本 0.4.x，早期阶段。

**风险与争议**:
- **vanity**: star/subscribers 约 180:1，热度靠创始人光环与媒体传播驱动，独立开发者采用证据稀薄。
- **bus_factor**: 贡献者全为 Block 员工，单组织主导。
- **stability**: 0.4.x 早期版本；"去中心化"实为单 relay，名实存在落差。
- **privacy**: 跨频道 Agent 权限边界属公开未解难题，agent 驱动的操作安全模型尚不成熟。

**技术备注**: Rust 实现，基于 Nostr 协议；创建于 2026-03，7-24 仍在活跃推送。

### [alibaba/open-code-review](https://github.com/alibaba/open-code-review) — NEW ⭐ 11,602（+180）| Go | 信源：中

**它是什么**: 阿里开源的命令行代码审查工具，让 AI 按内置规则自动挑出代码里的 bug 和安全隐患（空指针、线程安全、XSS、SQL 注入等），并在具体代码行上给出评论。

**解决什么问题**: 人工 code review 覆盖不全、规则不一致。它把确定性流水线 + LLM Agent 混合起来做行级审查，宣称在同一模型下比 Claude Code 精确率/F1 更高、token 仅约 1/9。阿里内部已用两年、覆盖 2 万+ 员工、检出超百万缺陷后才开源。

**谁在用、怎么用**（来自 Issues / HN）:
- Git diff 增量审查 + `ocr scan` 全文件审计；可作为 slash command 嵌入 AI coding agent。
- 社区在推扩展性: #472 加 Zig 支持、#470 扩展语言、#461 CLI 覆盖 REVIEW_FILTER_TASK、#458 运行时 `--provider` 切换。

**社区怎么评价**:
- 正面: HN 284 分 / 73 评，阿里规模化实战背书受关注。
- 负面: HN 核心质疑"误报率高会让开发者像对待高误报安全工具一样忽略告警"；项目回应是刻意"重精确率轻召回率"。
- 健康度: 11,602 ⭐ / 43 subscribers（≈270:1），open issues 47，贡献者 63 人但高度集中（头号 219 提交、第二名仅 21），仓龄约 2 个月。

**风险与争议**:
- **bus_factor**: 单一核心维护者，贡献极度集中。
- **vanity**: star/subscribers 比高、issue 讨论薄、独立第三方评测缺失，传播主要靠官方 + 媒体。
- **dependency**: 依赖 OpenAI/Anthropic 兼容 LLM。
- **cost**: 虽做了 token 优化，仍需付费 LLM。

**技术备注**: Go 实现，OpenAI & Anthropic 兼容；创建于 2026-05-18，当天仍有推送。
