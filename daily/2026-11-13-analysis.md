### [pookjw/HermesEnabler](https://github.com/pookjw/HermesEnabler) — NEW ⭐ 1,554（+218）| Objective-C | 信源：中

**它是什么**: 一个让普通 Apple Watch 用上 Hermès 版专属表盘的小工具，不用越狱。它由一个手表 App 和一个 iPhone 伴侣 App 组成，装好后在 App 里打开开关，手表就会把自己当成 Hermès 版；新版本还能解锁 Ultra 专属表盘。

**解决什么问题**: Hermès 表盘和 Ultra 表盘由 Apple 按机型限定，买的不是对应型号就选不到。以前想要这些表盘只能换表。这个工具改写手表里记录设备品牌的一份系统缓存（MobileGestalt），让系统放开表盘选择。issue #12 里有用户描述了机制：它利用的是系统容器查询里的一个沙箱缺陷。

**谁在用、怎么用**（来自 Issues/X）:
- 普通用户侧载后换表盘: 用 Sideloadly、Xcode 或 Windows 上的第三方工具把 App 签名装进手机和手表，两端都要打开开发者模式。#33 是一位用户在 iOS 27.0.1、watchOS 27.2.1 上用 Sideloadly 签名后的报错记录。
- 老机型用户自测兼容性: #17 是用户在 Ultra 1、watchOS 26.6.1 上的测试记录。README 写明当前只支持 watchOS 27.0 到 27.3 beta 1。

**社区怎么评价**:
- 正面: 多条 issue 开头先感谢作者。11-12 到 11-13 两天连发 1.5.1、1.5.2、1.5.3，最新版跟进了两个新的 watchOS 构建号，并把安装文档拆成 macOS 和 Windows 两份。
- 负面: #34（11 条评论）报告覆盖升级后备份丢失、开关自己弹回、手表端 App 消失；#58（10 条评论）报告 1.5 版打开 Ultra 表盘后关不掉；#28（7 条评论）报告 Series 10 的界面被放大和裁切。
- 健康度: 2024-12 建仓，1,554 星、5 subscribers，比值约 311:1；51 个 open issue、4 个 open PR。共 89 次提交，作者本人占 68 次。Hacker News 没有讨论；X 上的搜索结果显示作者 11-09 的发布帖是主要传播源，本次没有打开原帖核对。Reddit 未能检索。

**风险与争议**:
- **stability**: 工具改的是系统缓存，已有界面错乱和无法还原的报告（#58、#28、#34）。README 要求删除 App 前先在 App 内恢复备份。
- **dependency**: 功能依赖一个系统沙箱缺陷，只覆盖很窄的 watchOS 版本区间，Apple 修补后就会失效。
- **compliance**: 绕过了 Apple 对表盘的机型限定，并使用 Hermès 的品牌表盘；README 写明风险自负。
- **bus_factor**: 约四分之三的提交来自作者一人。

**技术备注**: Objective-C，MIT。免费 Apple ID 签名 7 天过期，需要重签；部分权限可能需要付费开发者账号。

**技术备注**: TypeScript，Apache-2.0。项目首发时的介绍称它改自 Google 的 Gemini CLI，GitHub 上它不是 fork 关系。今天上榜没有找到单一事件，时间上最接近的是 11-12 的 1.0 预览版。

### [ashhart/TensorFold](https://github.com/ashhart/TensorFold) — NEW ⭐ 1,951（+54）| Zig | 信源：中

**它是什么**: 一个在自己电脑或自己服务器上运行大语言模型的引擎。下载一个可执行文件，它就能加载模型，并对外提供和 OpenAI、Anthropic 接口兼容的服务，现有的客户端和 Agent 工具改一个地址就能接上。

**解决什么问题**: 在 Mac 上本地跑模型，常见做法要装 Python 和 MLX 一整套环境。TensorFold 用 Zig 写成一个原生程序，直接调用 Apple 的 Metal 和 NVIDIA 的 CUDA，README 称服务时不需要 Python。它近期的重点是长对话：v1.2.7（11-11）的发布说明称，Qwen3.8-27B 在 M3 Ultra 上续接一段长对话，首个 token 从约 85 秒降到约 0.3 秒。这些数字是作者自述。

**谁在用、怎么用**（来自 Issues/X）:
- 给新模型做适配: #1491（63 条评论）是 LFM3 两个模型在 Metal 上的原生支持，#559 是外部贡献者把 DeepSeek-V4.1-Flash 移植到 CUDA 后交回项目。
- 多机集群: #2005 是一份跨节点分层推理的 RFC，设想把 GB10 设备和 Mac 放进同一个模型的推理流程。
- 长对话场景的故障报告: #1312 记录 GLM-5.3-Flash 在 CUDA 上无法把对话状态存盘，一段 18.7k token 的对话被挤出内存后，下一轮要重算 15.6 秒。

**社区怎么评价**:
- 正面: 外部贡献者参与模型移植。X 上的搜索结果里有第三方在 RTX 5090 上的速度对比，结论对 TensorFold 有利，但各引擎用的量化格式不同、测的是旧版本，本次没有打开原帖核对，不宜当作基准。
- 负面: 仓库描述写了 Vulkan，README 前 100 行没有提到它，也没有和 llama.cpp 的对比数据。CUDA 上部分模型的功能还没补齐。
- 健康度: 2026-06 建仓，1,951 星、11 subscribers，比值约 177:1；198 个 open issue、341 个 open PR。5 个月 7,941 次提交、61 个版本，最近的提交都来自作者本人。Hacker News 没有讨论，Reddit 未能检索。

**风险与争议**:
- **bus_factor**: 最近的提交都由作者一人完成，README 用大段篇幅要求贡献者使用指定的 Agent 协作工具。
- **stability**: 两三天发一个版本，341 个 open PR 排队，升级前看发布说明里是否涉及自己用的模型和后端。
- **vanity**: 星数与 subscribers 的比值偏高，但 issue 和 PR 里有具体模型、具体硬件的讨论，不能只凭比值判断。

**技术备注**: Zig，Apache-2.0。支持 Homebrew 安装，有 Linux 和 Windows 的 CUDA 版本；v1.2.7 新增 Responses API 的 WebSocket 模式。
