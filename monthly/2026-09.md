# GitHub Trending 月报 — 2026 年 9 月

_agent 竞争从「塞什么能力」挪到「什么时候允许动手」和「在哪台机器上动手」，Google、AWS、NVIDIA 在下旬接连放出执行底座；全月星增第一的是本地语音工作台 VoiceStudio，最容易核实的信号来自本地工具、严肃工具和发版驱动的老仓回流。_

_数据源: https://github.com/trending（daily）｜ 25 个 daily analysis（09-01 ~ 09-30，缺 09-12、09-17、09-25 ~ 09-27）+ 3 份周报（W36 ~ W38，W36 含 08-31）汇总，09-21 ~ 09-30 无周报、直接取自日分析 ｜ 全月 380 个榜位、191 个不同仓库（NEW 91 次 / RE 119 次 / 已上榜更新 170 次）_

## 月度趋势纵览

9 月的榜单可以按时间切成四段，每一段的主角都不一样：

- **上旬（09-01 ~ 09-07）：skill 盘包场，运行时与模型层跟着代码在走。** `mattpocock/skills`、`DietrichGebert/ponytail`、`affaan-m/ECC` 守住前三，同时 `NousResearch/hermes-agent`、`anomalyco/opencode`（首入 tracker，204,148 ⭐）、`magnitudedev/magnitude` 这批运行时项目持续在榜；`THU-MAIC/OpenMAIC`、`jingyaogong/minimind`、`debpalash/VoiceStudio` 撑起非 agent 一侧。
- **中上旬（09-08 ~ 09-13）：skill 从「比能力」改成「约束输出 + 团队分发」，然后整盘退场。** `ayghri/i-have-adhd` 一份 140 行 `SKILL.md` 两天登顶，腾讯 `teamai-cli` 把 skill 推到团队级 Git 同步；`openai/skills` → `openai/plugins` 换仓的错位三天自我修正；09-13 榜单上已没有任何通用 skill 仓。
- **中下旬（09-14 ~ 09-21）：回流先压过新供给，09-18 大厂带着能力包集体进场。** `alibaba/open-code-review` 5 天在榜、两天登顶；09-18 那天 20 项里 8 项来自组织账号，`cloudflare/security-audit-skill` 单日 +3,607；09-19 `Fission-AI/OpenSpec` 首入，09-20 `trycua/cua`、`coder/coder` 拉出运行环境这条线。
- **下旬（09-22 ~ 09-30）：执行底座与管理层成为主盘。** 09-23 `google/ax` 带着 HN 657 分首入，脚下的 `agent-substrate/substrate` 同日回榜；09-24 AWS 的 `strands-agents/harness-sdk` 入场；09-28 起 `paperclipai/paperclip`、`vectorize-io/hindsight`、`VoiceStudio` 连续三天包揽前列；09-30 `NVIDIA/OpenShell` 首入即排 #2。

围绕这四段，有四条贯穿全月的主线。

**主线一：agent 竞争越过「能力包」这一层，同时向上和向下延伸。** 8 月读者该问的是「我在哪一层选型」，9 月这些层开始有了更明确的分工：

- **向上：约束 agent 什么时候动手、产出怎么把关。** `i-have-adhd`（09-09 首入、两天登顶，30,662 → 38,467）和 `cathrynlavery/diagram-design`（6 天在榜）不给 agent 新增能力，只约束它说话和画图的形态；`OpenSpec`（69,373 ⭐ 首入）要求 agent 写代码前先产出提案 / 规格 / 设计 / 任务清单四份人可审的文档，审完才允许落地；`open-code-review` 用「确定性流水线 + LLM agent」在产出之后做门禁，内置 NPE、线程安全、XSS、SQL 注入规则集，月内 23,583 → 36,719。
- **向下：agent 在哪台机器上跑、跑坏了谁兜底。** `cua` 在 09-19 推出自研模型 CUA-S1 后回榜 #2；`coder` 把 agent 放进自托管、可断网、可审计的开发环境；下旬三家大厂各放出一层——`google/ax` 管「上万个 agent 任务怎么声明、调度、限流、挂起恢复」，README 写明跑在 `substrate` 沙箱之上；`strands-agents/harness-sdk` 是 AWS Strands Agents SDK 改名后的版本，HN 134 分 / 92 评；`NVIDIA/OpenShell` 用 Landlock 内核级沙箱隔离每个 agent，凭据只注入白名单端点的请求。
- **管理与记忆层在月末回到榜首。** `paperclip`（管 agent 团队的任务与审计，月末 94,737 ⭐）、`hindsight`（长期记忆，09-28 / 09-29 连续两天单日 +4,500 以上）、`mvschwarz/openrig`（把 Claude Code 和 Codex 编成一个多 agent 系统）、`akitaonrails/ai-memory`（一个月 star 翻倍，外部贡献者在修真实缺陷）。

**判断**：到 9 月底，agent 落地的选型已经可以按「记忆 / 隔离 / 编排 / 约束 / 工作材料」逐层对照，而且执行底座这一层第一次由 Google、AWS、NVIDIA 三家同月供给。但「harness」这个词同时被编排运行时（ax）、SDK（Strands）、办公运行时（`dream-num/univer` 自称 "The Office Harness for AI Agents"）和设计规范（`pbakaus/impeccable`）使用，比较这类项目要先看它实际接管哪一层，不要按名字归类。三家的底座都还在早期：`OpenShell` 9-25 才发 v0.1.0，Strands「比 Claude Code 便宜 77%」这类数字目前只有官方来源。

**主线二：skill 盘走完一个完整周期，回来时换成了厂商主体。** 上旬是 skill 盘最后一次「个人仓包场」：`mattpocock/skills` 09-05 登顶，五天 245,283 → 254,687；`ponytail` 五天 121,676 → 129,479；`ECC` 全月 13 天在榜、为在榜天数第一，245,272 → 263,788。09-08 起形态变了，新增供给从能力换成规范（`i-have-adhd`、`diagram-design`、`multica-ai/andrej-karpathy-skills`）和分发（`teamai-cli` 的 `src/known-agents.ts` 列了 34 个 agent 的 skill 目录约定）。09-13 整盘退场，09-18 再回来时上榜的是 Cloudflare、腾讯、Anthropic 的能力包——`security-audit-skill` 整仓 143KB、主体是 markdown 提示词加少量脚本，四天 10,764 → 18,080；`Tencent/BrowserSkill` 让任意能跑 shell 的 agent 借用你电脑上已登录的真实浏览器。**判断**：skill 这一层入场门槛低到十几个文件就能拿到单日最大增量，所以竞争很快从「谁的包更全」挪到了「谁来出、怎么约束、怎么分发」。读榜时 skill 类的 NEW 要多问一句：它交付的是能力、形态，还是流程。

**主线三：全月星增第一在本地 AI 应用，本地与自托管工具每周都有新切面。** `VoiceStudio` 把声音克隆、视频配音、有声书生成搬到本机，646 种语言、不按字符计费，09-03 首入 14,827 ⭐，月内 9 天在榜、涨到 48,854（+34,027，全月第一），9-22 / 9-23 连发 v0.5.5 / v0.5.6，09-28 ~ 09-30 三连榜首；v0.5.0 时已有 47,464 次下载，是比 star 更硬的采用证据。其他切面：

- **在自己机器上跑大模型的决策链**（09-11 同日在榜）—— `AlexsJones/llmfit` 解决选型，`JustVugg/colibri`（纯 C，把 MoE expert 权重留在 NVMe 按需读入，09-11 首入、五天在榜）解决跑不动怎么办，`diegosouzapw/OmniRoute` 解决跑不动就别跑（聚合 352 家供应商）；上旬的 `magnitude` 在本机起推理服务，接到 Claude Code / Codex / OpenCode 下面。
- **agent 的上网层**（09-08）—— `jo-inc/camofox-browser` 与 Zig 写的 `lightpanda-io/browser` 两条相反路线同日首入，都绕不开目标站 ToS 与 robots.txt 的边界问题。
- **开发者自托管工具**（09-30）—— 25 MB 的 Rust 数据库客户端 `t8y2/dbx`（支持 100+ 种数据库，含达梦）、自托管部署平台 `oblien/openship`；它们和 8 月的 `OpenLogi` 一样，把 AI 或 MCP 接口当默认能力而不是插件。

**判断**：这条线不像 agent 底座那样有大厂叙事，但它的采用证据最直接——下载量、硬件适配 issue、可复现的部署报障。如果只想找「下个月还会在用的东西」，从这里找比从 skill 盘找靠谱。

**主线四：回流多于新供给，严肃工具与老仓首入的密度异常高。** 全月 RE 119 次、NEW 91 次，NEW 占榜位比例从 8 月的 27% 降到 24%。回流分两类，在榜上都标 `RE`，看起来一样：

- **能对上具体事件的**——`rustfs/rustfs` 1.0.0 GA、`ankitects/anki` 26.09 安全版本、`asciimoo/hister` HN 695 分、`cilium/cilium` 三个维护分支同日补丁、`dream-num/univer` 9-23 发 1.0（日增 +255 → +1,142）、`hindsight` / `paperclip` 按版本回榜。
- **对不上事件的**——`jamiepine/voicebox` 四十天无提交仍 +667、`Open-Dev-Society/OpenStock` 一个月只有两次 README 更新却 4 天在榜、`666ghj/MiroFish` 近三次提交全是 star history、`NawfalMotii79/PLFM_RADAR` 最后推送停在 6-17。

老仓首入 tracker 也很密：W37 有 6 个、W38 有 11 个（`anki`、`cilium`、`supabase`、`coder`、`cloudflare/quiche`、`docling` 等），下旬还有 Amnesty 安全实验室的手机取证工具 `mvt-project/mvt`（每周一发版，09-22 首入后日增从 +169 涨到 +543）、UIUC 系统编程教材 `cs341-illinois/coursebook` 和 2016 年的 Go 压测工具 `rakyll/hey`。**判断**：区分两类回流只需要一个动作——点开最近一次提交看它改了什么；老仓密集填满周末榜单，通常意味着当天没有足够强的新叙事。

## 重点项目导读

按「读者最可能点开、且点开后有东西可看」排序。

### 1. [debpalash/VoiceStudio](https://github.com/debpalash/VoiceStudio) — 全月星增第一的本地语音工作台

把 ElevenLabs 那一套（声音克隆、声音设计、视频配音、听写、转写、有声书）整体搬到本机。9 天在榜、14,827 → 48,854，月内发版节奏稳定（v0.5.5 加跨语种克隆、v0.5.6 跟进），09-29 合入 LLM provider 连接池的更新（#2407）。适合有大量配音或有声内容需求、又不想按字符付费的人。注意它是 AGPL-3.0 应用层，下游模型各自有许可，嵌入商业产品前要分开判断。

### 2. [alibaba/open-code-review](https://github.com/alibaba/open-code-review) — 产出之后的门禁

「确定性流水线 + LLM agent」混合架构，给出行级评论，内置多语言规则集，阿里内部规模验证过，Apache-2.0。09-14 ~ 09-19 五天在榜，两天登顶，期间近乎日更发版（v1.12.1 ~ v1.12.5），open issue 从 163 涨到 227 且持续有人回应。和同期 `security-audit-skill` 形成对照：一个做成独立工具加流水线，一个做成挂在别人 agent 上的提示词包。想给团队的 agent 产出加一道审查的人，可以先从它看起。

### 3. [google/ax](https://github.com/google/ax) + [agent-substrate/substrate](https://github.com/agent-substrate/substrate) — Google 的两层 agent 底座

`substrate` 负责 agent 在哪个沙箱里跑（8 月已上榜，Kubernetes 原生、gVisor 快照），`ax` 负责上万个 agent 任务怎么声明、调度、限流、挂起恢复。`ax` 的触发事件完全可查：09-20 Google 工程师 Jaana Dogan 在 X 揭幕并发 v0.3.0，HN 首页第一、657 分 / 297 评论；同一仓库 5 月的早期预览帖只有 2 分——引爆它的是正式发布，不是仓库被「发现」。两者都还在早期版本，适合在做大规模 agent 编排的团队做技术跟踪，暂不适合直接进生产。

### 4. [NVIDIA/OpenShell](https://github.com/NVIDIA/OpenShell) — 放权给 agent 之前先关进笼子

agent 要读文件、装包、调 API、拿密钥才有用，但直接放权风险很大。OpenShell 用 Landlock 内核级沙箱隔离每个 agent，按声明式策略控制文件、系统调用与网络访问，凭据只注入发往白名单端点的请求。09-25 ~ 09-28 连发 v0.1.0 ~ v0.1.2，09-30 首入即排 #2（10,881 ⭐）。它补上的是 8 月底「执行环境」那一层最缺的安全边界，10 月值得看是否有第三方集成。

### 5. [Fission-AI/OpenSpec](https://github.com/Fission-AI/OpenSpec) — 先审规格、再让 agent 动手

不给 agent 加能力，而是在 agent 写代码之前逼出四份人可审的 Markdown，审完才允许 `/opsx:apply` 落地。09-16 HN 主帖 196 分 / 98 评，09-19 带着 69,373 ⭐ 首入 tracker。HN 上的主要批评是「规格漂移」：代码改了而规格没跟上怎么办，#1697 还报了一处流程死锁。适合已经在用 coding agent、但被「它一上来就动手」困扰的团队。

### 6. [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill) — 厂商能力包的代表

把安全审计流程做成 agent 可加载的 skill：findings 分 confirmed / needs_validation / rejected 三类，配覆盖率台账和两个零依赖校验器（65 个测试），要求在无外网的 OS 级沙箱里执行目标代码。09-17 HN 194 分，09-18 起四天在榜、两天登顶。值得读它的设计，但要知道 issue #21 指出覆盖率校验器不检查 artifact 是否真实存在，HN 上一致质疑其 token 成本。

### 7. [JustVugg/colibri](https://github.com/JustVugg/colibri) — 显存不够也想跑 MoE

纯 C 实现，把 MoE 模型的 expert 权重留在 NVMe 上按需流式读入。09-11 首入，五天在榜，27,484 → 35,767，09-14、09-15 连续两天登顶。它回答的是本地推理里最实际的问题：跑不动怎么办。社区关注的 #1405（Windows/CUDA 构建链）和 #1294（可复现 benchmark 协议）在月内未见进展，选用前先用自己的硬件实测。

### 8. [dream-num/univer](https://github.com/dream-num/univer) — 从表格 SDK 改写成「给 agent 的办公运行时」

2022 年建仓，09-18 才把 README 换成 "The Office Harness for AI Agents"，五天后上榜。首入时主仓近 25 个 commit 都是表格的常规功能、没有 agent 相关代码；09-23 发布的 1.0 把六个编辑器（Sheets / Docs / Slides / Boards / Bases / PDFs）并进一个 Office SDK，并新增 Server SDK 和 AI SDK，叙事这才有了可以对照代码核实的交付。月内 5 天在榜，15,489 → 21,981。

### 9. [mvt-project/mvt](https://github.com/mvt-project/mvt) — 久违的严肃取证工具

Amnesty International 安全实验室 2021 年在 Pegasus Project 调查中放出的手机取证 CLI，09-22 首次进入 tracker。每周一发版（v2026.9.1 / 9.7 / 9.14 / 9.21），48:1 的 stars/subscribers 比对成熟工具属正常量级，open issue 只有 54。可查证的弱关联是 9 月初 Citizen Lab / Amnesty 确认塞尔维亚学生运动成员 iPhone 遭 Pegasus 零点击感染。记者、NGO 和安全从业者值得收藏。

### 10. [vectorize-io/hindsight](https://github.com/vectorize-io/hindsight) + [paperclipai/paperclip](https://github.com/paperclipai/paperclip) — agent 的记忆层与管理层

`hindsight` 3 月首入时 6.7K ⭐，09-30 已到 43,168，09-28 / 09-29 连续两天全榜日增第一，月内合入 Hermes Agent 集成和「编辑中的事实被并发整理覆盖」的修复（#4831）。`paperclip` 管 agent 团队的任务分派与审计，09-21 发 v2026.916.1，自 8-13 上次在榜累计 +12,147，月末 94,737 ⭐。两者都在按版本稳定迭代，可以按成熟度而不是新鲜感评估；`hindsight` 的社区足迹仍明显落后于 star 增速（见下节）。

## 如何理解热度信号

方法与前几个月一致，这里只写 9 月新增的校准点：

- **排名和日增是两回事。** 09-21 `ECC` 以 +826 排榜首，而当日增量第一的 `security-audit-skill`（+2,428）排第 3；09-24 榜首 `anthropics/financial-services` +664，低于 #2 `ax`（+1,543）和 #16 `browser-use/video-use`（+746）。需要比较热度时看日增和累计增长，不看名次。
- **stars/subscribers 比值只能用来起疑，不能用来定性。** 09-23 三个新面孔的比值都高（`superdesigndev/treg` 321:1、`ax` 213:1、`univer` 120:1），成因却完全不同：ax 是正式发布带来的尖峰，treg 靠作者自己的 X 影响力与 Discord 社区，univer 是老仓长期沉淀（fork/star 达 9%）。9 月新增的基准线：内容型仓 23:1（`ruanyf/weekly`）、成熟 CNCF 项目 80:1（`cilium`）、取证工具 48:1（`mvt`）、工具站型 279:1（`gitdiagram`）。
- **单语种社区的真实使用会被英文信源低估。** `jiji262/douyin-downloader`、`TencentCloud/Octop`、`yynxxxxx/Codex-X`（Release 下载三万多次）、`sngyai/Sequoia-X`、`zyronon/TypeWords` 在 HN / Reddit 上几乎查不到，但在 V2EX、知乎、HelloGitHub 和 issue 区有多方互证的真实用户。信源清单要按项目的用户群调整。
- **「回流」先看最近一次提交改了什么。** 同样标 `RE`，`rustfs` 的 1.0 GA 和 `MiroFish` 的 star history 自动提交在榜单上长得一样。
- **「代码在动」和「star 在涨」要分开看。** 上旬三个头部 skill 仓的最近提交分别是链接检查排除项、dependabot 升级和徽章排版；同期 `hermes-agent`、`opencode`、`magnitude` 每天都有实质提交。`security-audit-skill` 三天零提交而 star 涨了 5,683，是 W38 最大的一处背离。
- **组织账号不等于官方背书的完整开源。** `Octop` 是 MIT、代码公开、真有人部署，但核心依赖三个不在 GitHub 上的包。新增的检查项：把依赖清单逐个搜一遍，确认它们真的存在且可获取。

## 风险观察

按需要读者立刻采取行动的程度排序，均为当月日分析与周报中已核实的样本。

- **闭源内核套开源外壳（`TencentCloud/Octop`）。** 自托管多用户 AI 助理，NAS 与飞牛 OS 上有真实部署，但核心依赖 `orcakit-harness-agent` / `harness-memory` / `harness-gateway` 在 GitHub 上不存在；维护者在 #695 回复「等 octop 的热度继续提升后，我们会陆续开源」。部署前要知道：内核什么时候开源，取决于它的热度曲线。
- **会造成不可逆后果的工具。** `tradesdontlie/tradingview-mcp` 有静默覆盖已保存脚本（#475）、删光全部 alert（#527）的实测报告，195 个 open PR 无人合并，而 TradingView 官方 MCP Server 已进 public beta；`The-Swarm-Corporation/AutoHedge` 要求把 Solana 钱包私钥写进 `.env` 交给 agent 执行链上交易，质疑 README 与 pip 包内容不符的 #42 零回复；`yynxxxxx/Codex-X` 附带越狱提示词模板，#46 已有用户报告按模板操作后次日收到 OpenAI 封号警告。
- **把已登录的浏览器或真实环境交给 agent。** `Tencent/BrowserSkill` 直到 0.3.0 才把 `--unattended`、`--no-confirm` 收紧到不能绕过确认，prompt injection 目前没有缓解方案；`vastsa/PI-Desktop` 的插件信任模型是「用户信任代码」而不是 OS 级沙箱。下旬 `OpenShell`、`substrate` 这类隔离层的出现，正是在补这一块。
- **验证机制自身的漏检。** `security-audit-skill` 的覆盖率校验器不检查 artifact 是否真实存在（#21），两套测试各有一条「因错误原因通过」（#36），在非 Cloudflare 系 agent 平台上会整波静默失败（#13）；`cilium` 一次性修掉 9 个「配置被接受但静默忽略」的项（#47635 / #47637），用户可能长期以为某项防护已开启。
- **热度与社区足迹不匹配的样本。** `vectorize-io/hindsight` 月末 stars/subscribers 在 451 ~ 464:1，近两周 HN 找不到以它为主题的帖子，但提交与发版真实活跃——这是需要结合采用证据判断，而不是判空心；`rlaope/oh-my-hermes` 272:1、仓龄 3 个月、HN / Reddit 零讨论，「1,284 个 PR」大多由作者本人及其两个 AI 账号产出，且主推 `curl … | sh` 一键安装；`higgsfield-ai/higgsfield` 显示活跃、实际停更两年半且已装不上（#56）；`corsairdev/corsair` 用 AI credits 悬赏换 PR，同时抬高了 star、fork 和 PR 三个数字。
- **短龄、单核心维护者。** 09-28 的 4 个 NEW 主力作者各占几乎全部提交（openrig 1,485 : 1、scriptc 734 : 13）；09-30 的 `dbx` 1,299 个 open issue、`openship` 头号贡献者 1,071 次提交对第二名 50 次。真实用户反馈存在，「能不能长期用」还需要时间验证。
- **许可与合规，大多不在徽章上。**
  - AGPL-3.0：`VoiceStudio`、`coder`、`OpenStock`、`hister`、`Homebrew/BrewUI`、`lightpanda`；部分企业明令禁用。
  - 多档许可与商标：`ever-co/ever-gauzy` 的 AGPL 徽章只是三档许可里最低一档。
  - 代码与权重许可分离：`multimodal-art-projection/YuE` 代码 Apache-2.0、权重 CC BY-NC 4.0。
  - 衍生自泄露源码：`Gitlawb/openclaude` 的 License API 返回 `NOASSERTION`，与 README 的 MIT 徽章不一致。
  - 无许可或付费内容复述：`liquidslr/system-design-notes` 无 LICENSE，正文是付费书的逐章复述，下游已有人重排成书另开仓。
  - 平台 ToS：`douyin-downloader`、`omniget`、`camofox-browser`、`MG1937/ASC`（反编译商业 APK）。
- **攻击性内容的下游失控（`SnailSploit/Claude-Red`、`bikini/exploitarium`）。** Claude-Red 的 78 个攻击性 `SKILL.md` 被第三方注册表自动转分发后，Windows Defender 报出 Severe 级告警（#4），维护者还在 #6 建议用户研究越狱；exploitarium 的 40 多个漏洞 PoC 绝大多数未通知厂商，HN 高票评论逐条质疑其成立性。

## 值得关注的信号

1. **执行底座这一层第一次有三家大厂同月供给。** Google（ax + substrate）、AWS（Strands harness-sdk）、NVIDIA（OpenShell）在 09-23 ~ 09-30 一周内先后上榜，加上 8 月的 Cloudflare computer。10 月该看的是：有没有第三方生产案例和独立 benchmark，以及它们是否开始互相兼容，还是各自绑定自家云。
2. **「harness」已经不是一个能用来分类的词。** 它同时指编排运行时、SDK、办公运行时和设计规范。做选型或写对比时，按「它接管了哪一层：记忆 / 隔离 / 编排 / 约束 / 工作材料」来分，比按名字分可靠。
3. **skill 的竞争主体从个人仓换成了厂商。** 9 月上旬还是个人 skill 仓包场，下旬上榜的 skill 来自 Cloudflare、腾讯、Anthropic。skill 分发的跨 harness 目录约定（`teamai-cli` 列了 34 种，`cloudflare/quiche` 都在仓内用 symlink 处理 `.opencode` 与 `.codex` 的差异）仍未收口，这个缺口正在扩散到与 agent 无关的仓库。
4. **约束层比能力层更值得投入。** 9 月最有操作价值的几个项目（OpenSpec、open-code-review、i-have-adhd）都不给 agent 新增能力，而是约束它什么时候动手、怎么说话、产出怎么把关。已经在团队里用 coding agent 的人，下一步投入可以优先放在这里。
5. **「开源」需要多一道依赖检查。** `Octop` 让「许可证 + fork 率 + issue 质量」这套检查全部通过，但核心依赖不存在。自托管类项目的评估清单应加上「逐个确认依赖可获取」。
6. **10 月值得继续跟的事**：`security-audit-skill` 的 #21 覆盖率校验漏洞与 token 成本有没有官方回应；`Octop` 的三个闭源依赖有没有开源；`univer` 的 agent 能力在主仓里能否用代码核实；`VoiceStudio` 能否在没有新版本时守住热度；`OpenSpec` 对「规格漂移」批评的回应。
7. **数据侧：覆盖从 8 月的 31/31 天明显回落。** 25/30 天有采集与分析，09-12、09-17、09-25 ~ 09-27 共 5 天缺失，09-21 ~ 09-30 没有对应的 W39 周报，本月报下旬部分直接取自日分析。缺失的 09-25 ~ 09-27 恰好落在 `OpenShell` 发版与 `hindsight` / `paperclip` 回榜之间，这一段的过渡无法逐日还原。NEW 条目的强信源比例也从 8 月的 44% 降到 26%，部分是因为月末单人仓与短龄仓增多。本月报统计一律以 `daily/2026-09-*.md` 榜单为准。
